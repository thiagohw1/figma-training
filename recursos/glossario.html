Glossário de termos

Todos os termos técnicos do Figma, de UI/UX e de design systems usados neste curso, em ordem alfabética — com definições claras e diretas.

Como navegar

Os termos estão em ordem alfabética. Use Ctrl + F (ou ⌘ + F no Mac) para buscar rapidamente qualquer palavra nesta página.

A

TermoDefinição
Affordance Qualidade visual de um elemento que indica como ele deve ser usado. Um botão com relevo "affordance" que deve ser clicado; um campo de texto com borda sugere que aceita entrada.
Alinhamento (Alignment) Posicionamento de elementos em relação a uma borda, centro ou a outros objetos. No Figma, disponível no painel direito para alinhar objetos selecionados.
Asset Qualquer recurso reutilizável no arquivo: ícones, imagens, componentes, estilos e variáveis. No Figma, acessados pelo painel Assets (Alt/⌥ + 2).
Auto Layout Recurso do Figma que transforma um frame em container inteligente, organizando os filhos em linha ou coluna com espaçamento automático. Equivalente visual ao Flexbox do CSS.

B

TermoDefinição
Boolean Operation Operações vetoriais que combinam formas: Union (junção), Subtract (subtração), Intersect (interseção) e Exclude (exclusão). Produzem novas formas a partir de duas ou mais.
Breakpoint Largura de tela específica em que o layout muda para se adaptar a dispositivos diferentes (ex.: 768 px para tablet, 1280 px para desktop). Essencial no design responsivo.
Branch (Figma) Cópia ramificada de um arquivo Figma, similar a uma branch de Git. Permite explorar mudanças sem afetar o arquivo principal, podendo ser mergeada depois.

C

TermoDefinição
Canvas A área infinita de trabalho do Figma onde todos os frames, objetos e anotações vivem. É possível navegar pelo canvas com a ferramenta Hand (H) ou scrollando com Space.
Component (Componente) Elemento reutilizável no Figma com um "mestre" (main component) e instâncias. Alterações no mestre se propagam para todas as instâncias — o fundamento dos design systems.
Component Property Propriedade configurável de um componente exposta para suas instâncias: pode ser texto, booleano (visibilidade), variante ou troca de instância (instance swap).
Constraint Define como uma camada se comporta ao redimensionar o frame pai: pode ficar fixada em relação à esquerda, direita, centro, topo, base ou escalar proporcionalmente.
Corner Radius Arredondamento dos cantos de um retângulo ou frame. Cada canto pode ser controlado individualmente. Aceita valores em px e suporta variáveis.

D

TermoDefinição
Design System Conjunto documentado de componentes, estilos, padrões e diretrizes que governa a linguagem visual de um produto. No Figma, materializado como biblioteca compartilhada.
Design Token Valor nomeado que representa uma decisão de design (ex.: color/brand/primary = #6c4cf1). Permite que estilos sejam sincronizados entre design e código sem duplicação.
Dev Mode Modo do Figma focado em handoff: exibe propriedades CSS, iOS e Android dos elementos, além de guias de distância e exportações. Acessível via Ctrl/⌘ + Shift + D.

E – F

TermoDefinição
Effect Efeito visual aplicado a uma camada: sombra projetada (Drop Shadow), sombra interna (Inner Shadow), desfoque de camada (Layer Blur) ou desfoque de fundo (Background Blur).
Fill Preenchimento de uma camada. Pode ser cor sólida, gradiente linear, radial, angular, diamond, ou imagem. Múltiplos fills podem ser empilhados com opacidade e modos de mesclagem.
Flow No contexto de prototipagem, o caminho de navegação entre frames. Pode ter um "Starting Point" para iniciar a apresentação.
Frame Contêiner fundamental do Figma — equivalente a uma <div> com posição absoluta. Pode representar uma tela, componente ou qualquer seção de layout. Diferente de um Group, aceita Auto Layout e Constraints.

G – H

TermoDefinição
Gap Espaço entre os filhos dentro de um Auto Layout. Pode ser um valor fixo em px ou Auto (distribui espaço disponível, como justify-content: space-between).
Grid (Layout Grid) Grade sobreposta a um frame para guiar o posicionamento dos elementos. Tipos: grid uniforme, colunas (para layouts responsivos) e linhas. Aparece somente na edição, não no export.
Group Agrupamento simples de camadas (Ctrl/⌘ + G). Diferente de um Frame: não aceita Auto Layout nem Constraints individuais por filho.
Handoff Processo de entrega do design ao desenvolvedor. No Figma, realizado via Dev Mode ou por links de inspeção que mostram medidas, estilos e código exportado.
HIG (Human Interface Guidelines) Diretrizes de design da Apple para iOS, macOS e plataformas relacionadas. Estabelecem padrões de usabilidade, tipografia e componentes para apps Apple.
Hug (Hug Contents) Opção de redimensionamento em Auto Layout em que o frame encolhe para "abraçar" seu conteúdo, crescendo e diminuindo junto com os filhos.

I – L

TermoDefinição
Instance (Instância) Cópia de um componente mestre. Herda todas as propriedades do mestre mas pode ter overrides locais (texto, imagem, variante). Atualizações no mestre propagam para as instâncias.
Instance Swap Propriedade de componente que permite trocar um ícone ou sub-componente por outro sem criar novo objeto. Muito usado em botões com ícones intercambiáveis.
Layer Qualquer objeto no Figma com nome e posição na pilha de camadas. Pode ser frame, group, texto, vetor, imagem, componente, seção, etc.
Library (Biblioteca) Arquivo Figma cujos componentes, estilos e/ou variáveis foram publicados e estão disponíveis para uso em outros arquivos da organização.

M – O

TermoDefinição
Main Component O "mestre" de um componente — a fonte da verdade da qual todas as instâncias derivam. Identificado por um diamante sólido (◆) no painel de camadas.
Material Design (Material 3) Sistema de design do Google para Android e web. A versão atual (M3 / Material You) enfatiza cores dinâmicas e personalização. Possui kit oficial na Figma Community.
Mode (Modo) Configuração de variáveis que define um conjunto de valores. Exemplos: "Light" e "Dark", "PT-BR" e "EN", "Mobile" e "Desktop". Permite trocar toda a paleta ou textos com um clique.
Mockup Representação estática e detalhada de uma interface, com visual próximo ao produto final, mas sem funcionalidade interativa real. No Figma, é o arquivo de design em si.
Override Alteração feita em uma instância que sobrescreve a propriedade do componente mestre apenas localmente. Overrides são mantidos mesmo quando o mestre é atualizado.

P – R

TermoDefinição
Padding Espaço interno entre a borda de um frame com Auto Layout e seus elementos filhos. Pode ser configurado uniformemente ou separadamente por lado (top, right, bottom, left).
Page Divisão interna de um arquivo Figma. Cada page tem seu próprio canvas infinito. Útil para organizar fluxos, versões ou seções de um produto no mesmo arquivo.
Prototype Simulação interativa do produto criada no Figma conectando frames com conexões de navegação. Permite testar fluxos de usuário sem código.
Responsive Resize Capacidade de um frame ou componente se adaptar ao redimensionamento, controlada por Constraints e Auto Layout. Base do design responsivo no Figma.

S

TermoDefinição
Section Container organizacional no canvas (sem afetar o layout dos filhos). Não exporta como camada. Usado para agrupar frames por fluxo, status ou sprint no canvas.
Slice Ferramenta de recorte de exportação. Permite exportar uma área específica do canvas, independente das camadas.
Smart Animate Transição de protótipo que interpola automaticamente as diferenças entre dois frames com camadas de mesmo nome. Cria animações suaves sem configuração manual.
Stroke Borda (contorno) de uma camada. Configurável em cor, espessura, posição (interna, central ou externa) e estilo de linha (sólida, tracejada, pontilhada).
Style (Estilo) Conjunto nomeado de propriedades visuais reutilizáveis: Color Styles (cores), Text Styles (tipografia), Effect Styles (sombras/blurs) e Grid Styles. Substituídos gradualmente por Variables.

T – V

TermoDefinição
Token Ver Design Token. No Figma, implementado via Variables. Em pipelines de código, exportado via plugins como Tokens Studio ou Style Dictionary.
UI Kit Biblioteca de componentes prontos que seguem um sistema de design específico (iOS, Material, etc.). Acelera o início de projetos com componentes já construídos.
Variable (Variável) Valor nomeado e reutilizável no Figma (cores, números, strings, booleanos) que suporta múltiplos Modes. Substitui e supera os Color Styles ao permitir temas dinâmicos.
Variant (Variante) Variação de um componente dentro de um conjunto (Component Set). Permite ter em um único componente todas as versões (ex.: botão primário/secundário, tamanho small/medium/large).
Vector Network Sistema vetorial exclusivo do Figma que permite criar caminhos não-lineares — pontos podem ter múltiplos segmentos divergindo, sem a limitação do modelo de caneta tradicional.

W – Z

TermoDefinição
WCAG Web Content Accessibility Guidelines — diretrizes internacionais de acessibilidade digital do W3C. Define critérios de contraste, legibilidade e interação para níveis A, AA e AAA.
Wireframe Esboço estrutural de uma interface em baixa fidelidade, focado em layout e hierarquia sem definir cores ou visual final. Etapa exploratória antes do design de alta fidelidade.
Wrap (Auto Layout) Modo de Auto Layout que "quebra" os filhos para a próxima linha quando não cabem na largura disponível — similar ao flex-wrap: wrap do CSS. Ideal para grades de tags e galerias.
Termos não encontrados aqui?

O glossário cobre os termos mais frequentes do curso. Para conceitos mais avançados de tipografia, acessibilidade ou engenharia de UI, consulte a documentação oficial do Figma ou o IxDF (Interaction Design Foundation).
