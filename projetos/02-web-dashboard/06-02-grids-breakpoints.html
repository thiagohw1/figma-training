Layout grids e breakpoints para web

Grids não são decoração — são a espinha dorsal matemática do seu design. Configurar o grid certo no Figma garante que cada elemento se alinhe perfeitamente e que o desenvolvedor consiga traduzir o layout para CSS sem surpresas.

⏱️ Leitura: ~22 min 🎯 Nível: Projeto prático 🛠️ Pratique no Figma

Ao final desta lição você será capaz de

  • Configurar um Layout Grid de 12 colunas no Figma para desktop, tablet e mobile;
  • Definir container max-width, gutters e margens laterais para cada breakpoint;
  • Criar frames corretamente dimensionados para 1440, 1280, 768 e 375 px;
  • Usar Styles para salvar os grids e reutilizá-los em todos os frames do projeto;
  • Entender como o grid do Figma corresponde ao CSS Grid e ao framework de colunas.

Por que o grid de 12 colunas?

O sistema de 12 colunas é onipresente no design web — do Bootstrap ao Tailwind, do Material Design ao Ant Design — porque 12 é divisível por 2, 3, 4 e 6. Isso significa que você pode criar layouts de metade, terços, quartos e sextos sem cálculos fracionários. Uma sidebar de 3 colunas + conteúdo de 9 colunas? Perfeito para um dashboard. Três cards de 4 colunas? Ideal para uma linha de KPIs.

Grid no Figma vs. Grid no CSS

O Layout Grid do Figma é uma visualização de referência — ele não gera código, mas comunica ao desenvolvedor exatamente as métricas do sistema de colunas (grid-template-columns, gap, max-width, padding) para replicar fielmente no CSS.

Os três conceitos do sistema de colunas

1. Colunas (Columns)

O número de divisões verticais do layout. No desktop usamos 12; no tablet podemos usar 8; no mobile, 4. Cada coluna tem uma largura calculada automaticamente pelo Figma com base na largura do frame, no número de colunas, nos gutters e nas margens.

2. Gutters

O espaço entre as colunas. No design de produtos web, um gutter de 24 px é um valor clássico para desktop. É esse espaço que impede os blocos de conteúdo de colarem uns nos outros, criando respiração visual.

3. Margens (Margins)

O espaço entre o conteúdo e as bordas do frame — equivalente ao padding no container CSS. Em um container de 1440 px com conteúdo máximo de 1280 px, a margem de cada lado é de 80 px. No mobile de 375 px, a margem cai para 16–20 px.

Sistema de grid: margens (espaço nas bordas) + colunas (divisões de conteúdo) + gutters (espaço entre colunas). No desktop, são 12 colunas.

Breakpoints do TaskFlow

Breakpoints são as larguras em que o layout muda de comportamento — equivalentes aos @media queries no CSS. Para o TaskFlow, adotaremos três breakpoints principais:

Por que 1440 como referência principal?

Em 2025, a maioria dos monitores de laptop tem resolução nativa entre 1280 e 1920 px, e a resolução lógica mais comum em monitores externos 4K com 200% de escala é 1920/2 = 960 px. Usar 1440 px cobre bem o cenário mais comum de desktop sem ficar excessivamente largo. É o tamanho-padrão do Figma ao selecionar "Desktop".

Passo a passo: configurando os grids no Figma

  1. Selecione o frame de Desktop (1440). Na página Desktop (1440), selecione o frame 01 — Dashboard que você criou na lição anterior. Se não existir ainda, pressione F e escolha o preset Desktop → 1440 no painel direito.
  2. Adicione um Layout Grid. No painel direito, localize a seção Layout grid e clique no +. Um grid uniforme (tiles) aparece por padrão. Precisamos mudar para colunas.
  3. Configure o grid de colunas. Clique no ícone de grade para abrir as opções. Mude:
    • Type: Columns
    • Count: 12
    • Type (sizing): Stretch (as colunas preenchem o espaço disponível)
    • Gutter: 24
    • Margin: 80
    • Color: azul com ~10% de opacidade (para não poluir o design)
  4. Salve como Style. Clique no ícone de quatro pontos ao lado do grid na seção Layout grid e escolha Create style. Nomeie-o Grid/Desktop 1440. Agora você pode aplicar esse grid a qualquer frame com um clique.
  5. Repita para tablet e mobile. Crie frames de 768 e 375 px e configure os grids conforme a tabela acima. Salve como Grid/Tablet 768 e Grid/Mobile 375.
  6. Adicione um grid de linha (rows) opcional. Clique no + novamente e adicione um segundo grid do tipo Rows com altura de 8 px e cor vermelha a ~8% de opacidade. Isso cria uma grade de 8 px — sua unidade base de espaçamento.
  7. Visualize/oculte o grid. Use Ctrl + Shift + 4 (Windows) / ⌘ + Shift + 4 (Mac) para alternar a visibilidade do grid. Você vai usar isso centenas de vezes ao longo do projeto.
Dica de profissional: grid dentro de grid

O frame do dashboard ocupa a área de conteúdo da tela (excluindo a sidebar). Na prática, muitos times criam um frame interno apenas para a área de conteúdo com seu próprio grid de 12 colunas — assim o grid se alinha ao conteúdo, não à tela inteira. Experimente os dois e veja qual comunica melhor para o seu time.

Como o grid do Figma vira CSS

Veja a correspondência direta entre as configurações do Figma e o código CSS que o desenvolvedor vai escrever:

/* Desktop 1440 — equivalente ao grid configurado no Figma */
.container {
  max-width: 1280px;      /* container máximo */
  margin-inline: auto;   /* centraliza */
  padding-inline: 80px;  /* margem lateral do Figma */
}

.grid-12 {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 24px;             /* gutter do Figma */
}

/* Tablet 768 */
@media (max-width: 768px) {
  .container { padding-inline: 24px; }
  .grid-12 { grid-template-columns: repeat(8, 1fr); gap: 20px; }
}

/* Mobile 375 */
@media (max-width: 375px) {
  .container { padding-inline: 16px; }
  .grid-12 { grid-template-columns: repeat(4, 1fr); gap: 16px; }
}

Resumo

  • O sistema de 12 colunas é universal no design web por ser divisível por 2, 3, 4 e 6.
  • Cada breakpoint tem suas próprias configurações de colunas, gutter e margens — configure e salve como Style.
  • Os valores do Figma mapeiam diretamente para max-width, gap e padding-inline no CSS.
  • Use Ctrl/⌘ + Shift + 4 para alternar a visibilidade do grid enquanto trabalha.
  • Crie um Style para cada breakpoint (Grid/Desktop 1440, etc.) e aplique com um clique em qualquer frame.
✍️ Exercício

Configure os 3 grids do TaskFlow

  1. Crie frames de 1440, 768 e 375 px na página correspondente do seu arquivo.
  2. Configure o Layout Grid em cada um conforme a tabela da lição (colunas, gutter, margem).
  3. Salve cada grid como Style com o nome correto (Grid/Desktop 1440, etc.).
  4. Adicione um segundo grid de linhas de 8 px no frame de 1440 px para usar como base de espaçamento.
Critério de sucesso: os 3 frames têm grids corretamente configurados e salvos como Styles. Ao clicar em qualquer frame novo e acessar Layout grid, o estilo aparece na biblioteca e pode ser aplicado em 1 clique.
🏆 Desafio

Layout adaptativo com blocos de conteúdo

No frame de 1440 px, esboce a distribuição de blocos do dashboard usando apenas retângulos coloridos (sem texto real, sem cores de marca). Use a regra de grid: KPI cards em 3 colunas cada, gráfico em 8 colunas, painel lateral em 4 colunas. Depois duplique o frame, redimensione para 768 px e redistribua os blocos em 8 colunas (2 cards por linha, gráfico em 8 colunas ocupando a linha toda). Isso é o wireframe de layout — a base para a lição de responsividade.

QuizTeste seu conhecimento

1. Por que o sistema de 12 colunas é o mais usado no design web?

  • Porque é o número de meses do ano e fica fácil de lembrar
  • Porque frameworks como Bootstrap foram os primeiros e estabeleceram o padrão
  • Porque 12 é divisível por 2, 3, 4 e 6, permitindo divisões inteiras de layouts comuns
  • Porque é o limite máximo que o CSS Grid suporta
12 é divisível por 2, 3, 4 e 6 — isso permite criar colunas iguais para metades, terços, quartos e sextos sem frações. É pura matemática a favor do design.

2. O que é o "gutter" em um sistema de grid?

  • O espaço entre as colunas de conteúdo
  • A margem lateral entre o conteúdo e a borda do frame
  • O número de colunas no grid
  • O espaço acima e abaixo de cada linha de conteúdo
Gutter é o espaço entre colunas. Já o espaço entre o conteúdo e as bordas do frame é a margem. Confundir os dois é o erro mais comum ao configurar grids.

3. Qual atalho alterna a visibilidade do Layout Grid no Figma?

  • Ctrl/⌘ + G
  • Ctrl/⌘ + Alt + G
  • Ctrl/⌘ + R
  • Ctrl/⌘ + Shift + 4
Ctrl/⌘ + Shift + 4 mostra/oculta todos os grids do canvas. É um dos atalhos mais usados durante o design de interfaces web.
