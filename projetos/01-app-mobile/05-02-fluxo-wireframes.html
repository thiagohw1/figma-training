Fluxo de usuário e wireframes

Antes de montar pixels coloridos, precisamos entender como o usuário se move pelo FinView. Nesta lição você vai mapear o fluxo completo, construir o sitemap e criar wireframes low-fi no Figma usando frames mobile reais — a base estrutural de tudo que vem a seguir.

⏱️ Leitura: ~22 min 🎯 Nível: Projeto prático 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Construir um user flow completo do FinView no Figma usando formas simples e conectores;
  • Criar um sitemap hierárquico das telas do app;
  • Produzir wireframes low-fi de todas as telas usando frames iPhone 16;
  • Detalhar o wireframe da tela Home com todos os seus elementos estruturais;
  • Usar a convenção de cinzas para wireframes e organizar os frames na page.

Por que planejar antes de prototipar?

A tentação de abrir o Figma e já criar telas bonitas é enorme — e é exatamente aí que a maioria dos designers iniciantes perde tempo. Imagine construir uma casa sem planta baixa: você pode até montar paredes, mas descobrirá no meio do caminho que um quarto ficou sem janela ou que a escada bloqueia a porta.

O mesmo vale para apps. Wireframes low-fi são baratos de fazer e baratos de mudar. Uma vez que você investe horas construindo a tela Home em alta fidelidade com gradientes, sombras e components, mudar a hierarquia de informação custa caro — psicologicamente e tecnicamente.

O que é um wireframe low-fi?

Um wireframe de baixa fidelidade (low-fi) usa apenas caixas cinzas, texto em placeholder e formas geométricas para representar a estrutura de uma tela. Sem cores de marca, sem ícones reais, sem tipografia específica. O objetivo é comunicar o que existe na tela e onde fica, não como fica. Isso mantém o foco na estrutura e evita que stakeholders se distraiam com detalhes visuais prematuros.

User Flow: o caminho do usuário

Um user flow é um diagrama que mostra os caminhos possíveis que o usuário percorre dentro do app, do ponto de entrada até atingir um objetivo. Para o FinView, o objetivo central é registrar uma transação e ver como isso impacta o saldo.

User flow simplificado do FinView. O fluxo principal é: Onboarding → Home → Adicionar Transação → Home (atualizado). O fluxo secundário inclui tabs da nav bar e detalhe de transação.

Notação de user flow no Figma

No Figma, user flows são construídos com formas básicas e conectores:

  • Retângulo com cantos arredondados: representa uma tela ou estado.
  • Losango: representa uma decisão (ex.: "usuário já tem conta? → sim/não").
  • Círculo com borda dupla: ponto de início ou fim do fluxo.
  • Seta sólida: fluxo principal (ação esperada do usuário).
  • Seta pontilhada: fluxo alternativo ou navegação por tab.
  • Ferramenta Connector: no Figma, use Shift + X para ativar o modo conector e ligar frames visualmente.

Passo a passo: wireframe da tela Home

A Home é a tela mais complexa do FinView — saldo, cartões em carrossel, lista de transações e tab bar. Vamos construí-la do zero:

  1. Crie o frame da tela Home. Na page 📐 Wireframes, pressione F e selecione iPhone 16 (390×844) no painel direito. Renomeie o frame para WF-01 — Home com duplo clique no nome.
  2. Adicione a Status Bar (barra de status do iOS). Crie um retângulo (R) de 390×50 px no topo. Fill: #1A1D23. Adicione três textos pequenos para simular: horário à esquerda ("9:41"), nome no centro ("FinView") e ícones de bateria/sinal à direita (use textos "●●●" como placeholder).
  3. Construa a seção do card de saldo. Crie um retângulo 390×160 px logo abaixo da status bar. Fill: #CDD2D9 (placeholder — será o gradiente no hi-fi). Dentro, adicione textos:
    • "Saldo total" — fonte 12 px, cor #5B6573
    • "R$ 4.832,50" — fonte 28 px, bold, cor #FFFFFF (simule com #1A1D23 no wireframe)
    • Dois badges menores: "↑ Receitas" e "↓ Gastos"
  4. Adicione a seção de cartões (carrossel). Abaixo do card de saldo, crie um Auto Layout horizontal (Shift + A) com três retângulos de 140×80 px, gap 12, padding 16. Cada retângulo representa um cartão de conta. Adicione texto "Nubank", "Itaú", "Dinheiro" em cada um. Esse é o carrossel de cartões.
  5. Crie o cabeçalho da lista de transações. Adicione um Auto Layout horizontal com "Transações recentes" (texto negrito) e "Ver tudo" (texto link) nos extremos. Use gap Auto para empurrar os dois para os lados. Padding vertical 12, horizontal 16.
  6. Adicione itens da lista. Crie um item de lista: Auto Layout horizontal, 390×64 px. Dentro: um quadrado 40×40 (ícone placeholder), um Auto Layout vertical com "Nome da transação" (bold 14 px) e "Categoria · Data" (12 px, muted), e "- R$ 00,00" alinhado à direita. Duplique (Ctrl/⌘ + D) 4 vezes para simular 5 transações.
  7. Construa a Tab Bar (barra de navegação inferior). Na base do frame, crie um retângulo 390×83 px. Fill: #FFFFFF. Dentro, crie um Auto Layout horizontal com 5 itens iguais, cada um com um quadrado 24×24 (ícone) e um texto pequeno abaixo ("Home", "Metas", "Add", "Cartões", "Perfil"). Um deles (Home) usa cor mais escura para indicar ativo.
  8. Organize tudo em Auto Layout vertical. Selecione todos os elementos dentro do frame e aplique Auto Layout vertical (Shift + A). Garanta que o frame pai (iPhone 16) tem Clip content ativado (no painel direito, em Layer). Isso garante que nada ultrapasse os limites da tela.
  9. Adicione uma nota de anotação. Use a ferramenta de comentário (C) ou crie um retângulo amarelo ao lado do frame com texto explicando a hierarquia. No wireframe profissional, você anota decisões de UX ("lista rolável até a tab bar", "carrossel de cartões snap a cada item").
Atalho para duplicar frames lateralmente

Ao criar múltiplos wireframes lado a lado, selecione o frame e pressione Alt + arrastar (Windows) ou ⌥ + arrastar (Mac) para clonar. Melhor ainda: selecione e pressione Ctrl/⌘ + D, depois mova com as setas do teclado. Manter um espaçamento consistente de 40 px entre frames é uma boa prática.

Dicas de organização na page de Wireframes

Uma page de wireframes bem organizada é um entregável de UX em si. Siga estas convenções:

  • Grade de frames: alinhe os frames em fileiras, 40 px de espaço entre eles. Use Tidy Up (Shift + Alt + clique na grade no painel direito) para alinhar automaticamente.
  • Numeração dos frames: prefixo WF- seguido de número (WF-01, WF-02...) para identificação fácil ao referenciar em comentários ou documentos.
  • Seções com Section Tool: agrupe frames relacionados com a ferramenta Section (Shift + S no Figma). Ex.: seção "Onboarding", seção "Fluxo principal", seção "Perfil".
  • Conectores entre frames: use a ferramenta Connector para ligar os wireframes visualmente, mostrando a navegação. Isso transforma a page em um mapa de interação.
Wireframe vs. protótipo: não confunda

Wireframes são documentos de estrutura, não protótipos clicáveis. Não gaste tempo adicionando interações no Figma nesta etapa — isso é trabalho da Lição 7. O wireframe precisa ser aprovado quanto à estrutura e hierarquia antes de você investir tempo em alta fidelidade. Mostre para alguém e pergunte: "Você entende o que cada parte faz?" — se a resposta for sim, o wireframe cumpriu seu papel.

🏆 Desafio

User flow do fluxo de onboarding com decisão

Construa no Figma o user flow completo do onboarding com lógica de decisão: o usuário que já tem conta deve seguir um caminho diferente (Login) do que o usuário novo (Cadastro + Setup inicial). Use losangos para os pontos de decisão, círculos para início/fim, e retângulos para telas. Adicione 2 caminhos alternativos além do fluxo principal. O resultado deve ser um diagrama legível por alguém que nunca viu o FinView antes.

QuizTeste seu conhecimento

1. Qual é a principal vantagem de criar wireframes low-fi antes de partir para o design de alta fidelidade?

  • Wireframes low-fi são mais rápidos de apresentar para o cliente final
  • O Figma só suporta exportação de wireframes, não de designs coloridos
  • Wireframes eliminam a necessidade de fazer prototipagem
  • Mudanças estruturais são baratas de fazer em wireframes, evitando retrabalho no hi-fi
A grande vantagem dos wireframes é o custo de mudança: alterar a hierarquia de uma tela em wireframe leva minutos. Fazer o mesmo após construir o hi-fi com components e estilos custa muito mais tempo. Wireframes permitem validar estrutura antes de investir em detalhes visuais.

2. No Figma 2025, qual ferramenta é usada para agrupar visualmente frames relacionados dentro de uma page?

  • Group (Ctrl/⌘ + G)
  • Section (Shift + S)
  • Frame dentro de Frame
  • Component Set
Sections (atalho Shift + S) são a ferramenta certa para agrupar frames relacionados em uma page — são como "pastas visuais" na canvas. Groups agrupam objetos em uma hierarquia; Sections agrupam frames sem criar um novo container de edição.

3. Em um user flow, o que um losango representa?

  • Uma animação de transição entre telas
  • O ponto de início ou fim do fluxo
  • Um ponto de decisão onde o usuário pode seguir caminhos diferentes
  • Um componente reutilizável de interface
Em diagramas de fluxo (flowcharts), o losango representa uma decisão com dois ou mais caminhos possíveis (ex.: "Usuário tem conta? → Sim → Login / Não → Cadastro"). O círculo representa início/fim, o retângulo representa uma tela ou ação.
