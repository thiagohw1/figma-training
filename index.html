Como usar este treinamento

Siga a ordem dos módulos

O conteúdo foi desenhado como uma trilha: cada módulo usa o que você aprendeu no anterior. Se você é iniciante, comece pelo Módulo 0 e siga em frente.

Pratique enquanto lê

Mantenha o Figma aberto em outra janela e refaça cada passo. Ao fim de cada lição há exercícios, desafios e um quiz para fixar.

Acompanhe seu progresso

Use o botão “Marcar lição como concluída” no fim de cada página. Seu progresso fica salvo neste navegador e aparece na barra do topo.

Dicas de navegação

Use a busca no topo (atalho /), a barra lateral para pular entre lições e Alt + ←/→ para avançar. Há também um botão de tema claro/escuro.

Trilha de aprendizado

Do conceito à entrega profissional, em 4 níveis + 2 projetos práticos:

Nível 0 · Fundamentos → Nível 1 · Iniciante → Nível 2 · Intermediário → Nível 3 · Avançado → 📱 Projeto Mobile + 🖥️ Projeto Web → 🎯 Pro

Como acompanhar na prática

Este é um curso instrucional: cada passo descreve exatamente o que fazer no seu próprio Figma (web ou desktop). Não distribuímos arquivos .fig prontos — você aprende construindo. Quando útil, indicamos arquivos e kits gratuitos da Figma Community para acelerar. Tudo o que você precisa para começar é uma conta gratuita do Figma.
