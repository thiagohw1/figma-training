Code generation e Dev Mode MCP

A distância entre design e código está encolhendo. Em 2025/2026, o Figma vai além de exibir specs — ele gera código e conecta o design diretamente a IDEs e agentes de IA através do Dev Mode MCP, tornando o handoff mais preciso e automatizável do que nunca.

⏱️ Leitura: ~26 min 🎯 Nível: Profissional 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Usar a geração de código nativa do Dev Mode (CSS, iOS/SwiftUI, Android/Compose);
  • Entender o que é Code Connect e como ele mapeia componentes Figma a componentes de código;
  • Compreender o que é o Dev Mode MCP e como ele conecta o Figma a IDEs e agentes de IA;
  • Configurar o MCP server para uso com ferramentas de IA em 2025/2026;
  • Exportar assets (ícones, imagens, SVGs) diretamente do Dev Mode.

Geração de código nativa no Dev Mode

Quando você seleciona um elemento no Dev Mode, o painel direito exibe não apenas as propriedades visuais, mas também um snippet de código gerado automaticamente. O Figma oferece três plataformas nativas de geração de código:

CSS (Web)

Para elementos HTML/CSS, o Figma gera declarações CSS prontas. Um botão com Auto Layout, por exemplo, gera:

/* Button */
display: flex;
flex-direction: row;
justify-content: center;
align-items: center;
padding: 12px 20px;
gap: 8px;

background: #6C4CF1;
border-radius: 8px;

font-family: 'Inter';
font-weight: 600;
font-size: 14px;
line-height: 1.2;
color: #FFFFFF;

Se o projeto usa Variables (design tokens), o Figma pode gerar o código usando os nomes das variáveis em vez de valores literais — por exemplo, color: var(--color-primary-600) em vez de color: #6C4CF1.

iOS / SwiftUI

Para projetos mobile Apple, o Figma gera código SwiftUI. Um Text com estilo tipográfico, por exemplo, produz:

Text("Confirmar pedido")
    .font(.system(size: 14, weight: .semibold))
    .foregroundColor(.white)
    .frame(width: 160, height: 44)
    .background(Color(red: 0.42, green: 0.30, blue: 0.94))
    .cornerRadius(8)

Android / Jetpack Compose

Para Android moderno, o Figma gera Kotlin com Compose:

Button(
    onClick = { },
    colors = ButtonDefaults.buttonColors(
        containerColor = Color(0xFF6C4CF1)
    ),
    shape = RoundedCornerShape(8.dp),
    contentPadding = PaddingValues(horizontal = 20.dp, vertical = 12.dp)
) {
    Text(
        text = "Confirmar pedido",
        fontSize = 14.sp,
        fontWeight = FontWeight.SemiBold
    )
}
O código gerado é ponto de partida, não código final

O código gerado pelo Dev Mode é uma spec executável, não um componente pronto para produção. Ele captura as propriedades visuais mas não tem lógica de negócio, acessibilidade, estados interativos nem se encaixa automaticamente na arquitetura do projeto. Trate como uma excelente referência — não como código para copiar diretamente.

Plugins de code generation

Além da geração nativa, o ecossistema de plugins do Figma oferece opções mais especializadas:

  • html.to.design / Builder.io: tenta gerar HTML/CSS completo a partir de frames;
  • React Code Generator: gera componentes React com styled-components ou Tailwind;
  • Figma to Flutter: gera widgets Flutter a partir de componentes;
  • Anima: gera código React/HTML com fidelidade alta ao design original.

A qualidade varia — quanto mais organizado o arquivo Figma (bom uso de Auto Layout, componentes e variáveis), melhor o código gerado.

Code Connect: design e código como um só

O Code Connect (lançado em 2024 e expandido em 2025) é uma solução da Figma para resolver um problema fundamental: o Dev Mode mostra o código do Figma, mas na prática os devs usam um componente real do código (ex: um <Button> do design system da empresa), não propriedades CSS literais.

Com Code Connect, você mapeia um componente Figma ao componente de código correspondente. Quando o dev seleciona aquele componente no Dev Mode, em vez de ver CSS genérico, ele vê:

<Button variant="primary" size="md">
  Confirmar pedido
</Button>

Isso é o import exato do componente da biblioteca da empresa. A configuração envolve um arquivo de configuração que vincula o componente Figma (pelo ID) ao componente de código (pelo caminho de import). O Figma publicou um CLI e SDK para facilitar essa configuração.

Por que isso é revolucionário

Sem Code Connect: o dev vê "display: flex; background: #6C4CF1; border-radius: 8px..." e precisa lembrar que isso é o componente Button do design system. Com Code Connect: ele vê diretamente <Button variant="primary">. Elimina a tradução mental e reduz drasticamente o risco de reimplementar algo que já existe.

Dev Mode MCP: Figma conectado a IDEs e IA

O capítulo mais recente e transformador da história do Dev Mode é o MCP server (Model Context Protocol). Lançado pela Figma em 2025 e expandido em 2026, o Dev Mode MCP permite que ferramentas externas — principalmente IDEs com IA e agentes de IA — leiam o design do Figma diretamente, sem que o desenvolvedor precise alternar entre telas.

O que é MCP?

O Model Context Protocol é um protocolo aberto desenvolvido pela Anthropic para padronizar como agentes de IA se conectam a fontes de dados e ferramentas externas. Um MCP server expõe recursos (neste caso, os dados do Figma) que qualquer cliente compatível pode consumir.

O Figma criou seu próprio MCP server que expõe o conteúdo do arquivo como contexto para IAs. Isso significa que um agente de IA (como o GitHub Copilot, Cursor, Claude Code ou outros) pode "ver" o design e gerar código fiel a ele.

Como funciona na prática (2025/2026)

O fluxo típico com o Dev Mode MCP é:

  1. Instale o MCP server do Figma. O Figma disponibiliza um pacote npm (@figma/devtools-mcp) que você instala globalmente ou localmente no projeto. Siga a documentação oficial em figma.com/developers/mcp.
  2. Configure sua ferramenta de IA. No Cursor, VS Code com Copilot ou outra ferramenta compatível com MCP, adicione o servidor Figma na configuração MCP do cliente. Você precisará de um token de API do Figma com permissão de leitura.
  3. Referencie o design na conversa com a IA. Na interface da IA, você pode dizer algo como: "Implemente o componente do frame 'Button/Primary' do arquivo Figma [link]". A IA acessa o MCP server, lê as specs do frame e gera o código.
  4. Receba código fiel ao design. A IA gera componentes com as exatas cores, tipografia, espaçamentos e estrutura do design — não uma aproximação genérica. Se o projeto usa Code Connect, a IA também vê o mapeamento para componentes existentes.
  5. Itere diretamente na IDE. Se o design mudar, você pede para a IA atualizar o código baseado no frame novo — o MCP server lê a versão mais recente do arquivo em tempo real.
O impacto do MCP no workflow de 2026

Times que adotaram o Dev Mode MCP relatam redução de 40–60% no tempo de handoff. O desenvolvedor não precisa mais alternar entre Figma e IDE para checar valores — a IA tem acesso direto ao design e pode responder perguntas como "qual é o token de cor deste botão?" ou "como fica o componente em estado desabilitado?" sem nenhuma troca de contexto.

O MCP server do Figma conecta o arquivo de design diretamente a IDEs com IA e agentes de IA, que leem specs e geram código fiel ao design.

Exportando assets no Dev Mode

Um dos usos mais práticos do Dev Mode é exportar assets sem precisar do designer. Qualquer desenvolvedor com acesso ao arquivo pode:

  1. Selecione o elemento a exportar. No Dev Mode, clique no ícone, ilustração ou imagem que deseja exportar.
  2. Acesse o painel de exportação. No painel direito, role até a seção Export. Se o designer configurou exports no elemento, eles aparecem aqui. Se não, você pode adicionar manualmente.
  3. Escolha o formato. Para ícones: SVG (preferível para web) ou PDF. Para imagens: PNG com o fator de escala desejado (1x, 2x, 3x para diferentes densidades de tela) ou WebP. Para iOS: use os presets de @1x/@2x/@3x. Para Android: dp/mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi.
  4. Clique em Export. O arquivo é baixado para a sua máquina. Para múltiplos assets, selecione vários elementos (com Shift + clique) e exporte todos de uma vez.
SVG acessível por padrão

Ao exportar ícones como SVG, verifique se o designer os nomeou corretamente (os nomes das layers viram atributos no SVG). Para ícones exportados do Figma, considere adicionar aria-hidden="true" no código se forem decorativos, ou aria-label se forem funcionais.

Exemplo de uso real

Uma equipe de produto está lançando um novo feature de notificações. O processo com Dev Mode MCP:

  1. O designer finaliza os componentes de notificação no Figma e marca como "Ready for dev";
  2. O desenvolvedor abre o Cursor IDE (com MCP do Figma configurado) e diz: "Implemente o componente NotificationCard do frame 'Notifications/Card' do Figma";
  3. O agente de IA acessa o Dev Mode MCP, lê as specs do frame — dimensões, cores (já mapeadas a tokens), tipografia, espaçamentos;
  4. O agente também vê o Code Connect configurado e sabe que deve usar o componente <Card> existente como base;
  5. O código gerado usa os tokens corretos (--color-feedback-info, --spacing-md) e a estrutura de componentes já estabelecida;
  6. O dev faz pequenos ajustes de lógica e acessibilidade — o visual já está correto.
MCP ainda evolui rapidamente

O Dev Mode MCP do Figma foi lançado em 2025 e continua recebendo atualizações frequentes em 2026. Verifique sempre a documentação oficial em figma.com/developers para as capacidades mais recentes, as ferramentas de IA compatíveis e as instruções de configuração atualizadas.

Resumo

  • O Dev Mode gera código CSS, SwiftUI e Compose nativamente — útil como spec executável, mas não como código de produção final.
  • Plugins de code gen estendem a geração para React, Flutter e outros frameworks.
  • Code Connect mapeia componentes Figma a componentes reais de código, tornando o Dev Mode "consciente" da biblioteca interna.
  • O Dev Mode MCP conecta o Figma a IDEs com IA e agentes de IA, que leem specs e geram código fiel sem troca de contexto.
  • Assets (ícones, imagens) podem ser exportados diretamente do Dev Mode em todos os formatos e escalas necessários.
✍️ Exercício

Geração de código e exportação de assets

Pratique a geração de código e a exportação:

  1. No Dev Mode, selecione um botão e copie o snippet CSS gerado. Cole num arquivo button.css e veja o resultado no navegador.
  2. Selecione um ícone no design e exporte como SVG. Abra o SVG num editor de texto e examine a estrutura gerada.
  3. Se tiver acesso a uma ferramenta de IA com suporte MCP (Cursor, Claude Code ou similar), configure o MCP server do Figma seguindo a documentação oficial e peça para gerar o código de um componente do seu arquivo.
  4. Compare o código gerado pela IA com o código gerado pelo Dev Mode nativo — anote as diferenças de qualidade e contexto.
Critério de sucesso: o CSS gerado reproduz fielmente as propriedades visuais do botão no navegador; o SVG exportado é limpo e utilizável; e você entende a diferença entre geração nativa e assistida por IA.

Pipeline design → código com IA

Configure o Dev Mode MCP em uma ferramenta de IA da sua escolha (Cursor, Claude Code, Copilot) e implemente um componente completo — card, modal ou formulário — usando a IA como gerador principal de código. A IA deve ler as specs do Figma via MCP e gerar o componente. Você só intervém para ajustes de lógica e acessibilidade. Documente o processo: quantas iterações foram necessárias? Qual porcentagem do código visual foi gerado automaticamente? O que ainda precisou de ajuste manual?

QuizTeste seu conhecimento

1. O que o Code Connect faz no contexto do Dev Mode?

  • Gera automaticamente código CSS para todos os elementos do arquivo
  • Conecta o Figma a repositórios Git para controle de versão de designs
  • Mapeia componentes do Figma aos componentes reais de código da empresa, mostrando o import correto no Dev Mode
  • Exporta o arquivo Figma como projeto React completo
O Code Connect cria um mapeamento entre o componente no Figma e o componente real na base de código da empresa. Quando o dev inspeciona aquele componente no Dev Mode, vê o import e uso correto — não CSS genérico.

2. O que é o MCP (Model Context Protocol) no contexto do Figma?

  • Um formato de arquivo para exportar designs do Figma
  • Um plugin para conectar o Figma ao GitHub
  • Uma extensão do VS Code para inspecionar specs do Figma
  • Um protocolo que permite agentes de IA e IDEs lerem dados do Figma para gerar código fiel ao design
O Dev Mode MCP expõe o conteúdo do Figma através do Model Context Protocol, permitindo que IDEs com IA (Cursor, Copilot, Claude Code) acessem specs de design diretamente e gerem código sem que o dev precise alternar entre telas.

3. Qual é a limitação mais importante do código gerado automaticamente pelo Dev Mode?

  • Captura propriedades visuais mas não inclui lógica de negócio, estados interativos nem se encaixa automaticamente na arquitetura do projeto
  • Só funciona para projetos com menos de 100 componentes
  • Gera código apenas em CSS, sem suporte a frameworks como React ou Vue
  • O código gerado expira após 30 dias e precisa ser regenerado
O código gerado automaticamente é uma spec executável — captura fidelmente as propriedades visuais, mas não tem lógica de negócio, estados interativos, acessibilidade completa nem considera a arquitetura específica do projeto. É um excelente ponto de partida, não código de produção.
