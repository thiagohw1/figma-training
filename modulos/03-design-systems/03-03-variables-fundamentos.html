Variables — fundamentos

Variables é a implementação nativa de design tokens no Figma — e, desde 2023, mudou completamente a forma de trabalhar com temas, espaçamentos e conteúdo dinâmico dentro de qualquer arquivo.

⏱️ Leitura: ~24 min 🎯 Nível: Avançado 🛠️ Pratique no Figma

Ao final desta lição você será capaz de

  • Identificar os quatro tipos de Variables (Color, Number, String, Boolean) e seus casos de uso;
  • Criar uma Collection e organizar variables em grupos lógicos;
  • Aplicar Variables a propriedades de preenchimento, stroke, texto, espaçamento e radius;
  • Usar Number variables para spacing e corner radius sistematizados;
  • Usar Boolean variables para alternar estados de visibilidade;
  • Decidir quando usar Variables e quando usar Styles.

O que são Variables no Figma?

Variables (lançadas em 2023 e constantemente evoluídas) são a implementação nativa de design tokens dentro do Figma. Elas permitem criar valores nomeados e reutilizáveis que podem ser aplicados a praticamente qualquer propriedade de layer, e — o recurso mais poderoso — podem ter múltiplos valores para diferentes Modes (tema claro/escuro, idioma, densidade…).

Antes das Variables, a forma de sistematizar valores no Figma era através de Styles (Color Styles, Text Styles, Effect Styles). Variables não substituem Styles completamente, mas estendem o que é possível com muito mais flexibilidade.

Variables vs. Styles — a diferença fundamental

Styles armazenam definições complexas — um gradiente com múltiplas paradas, um texto com família + tamanho + entrelinha + espaçamento, uma sombra com múltiplas camadas. Variables armazenam valores únicos e primitivos: uma cor sólida, um número, uma string, um booleano. Variables suportam Modes (temas); Styles não.

Os quatro tipos de Variables

1. Color (Cor)

Armazena uma cor sólida (RGBA). Pode ser aplicada a Fill, Stroke, e propriedades de cor de texto. É o tipo mais usado para design tokens de cor.

Limitação: Variables de cor suportam apenas cor sólida — para gradientes, ainda é necessário usar Color Styles.

2. Number (Número)

Armazena um valor numérico sem unidade. Pode ser aplicado a: Width, Height, Corner Radius, Gap (Auto Layout), Padding (Auto Layout), Stroke Width, Opacity e outros campos numéricos. É perfeito para criar uma escala de espaçamento sistematizada.

3. String (Texto)

Armazena uma cadeia de texto. Pode ser aplicada ao conteúdo de layers de texto. Muito útil para criar protótipos multilíngues (o texto muda conforme o modo/idioma) ou para preencher dados fictícios de forma consistente (nomes, endereços, datas).

4. Boolean (Booleano)

Armazena true ou false. Pode ser aplicado à propriedade Visibility de qualquer layer. Permite criar toggles que mostram/ocultam elementos, o que é muito útil para componentes com estados opcionais.

TipoPropriedades que aceitaCasos de uso comuns
Color Fill, Stroke, Font color Tokens de cor, temas claro/escuro, paleta de marca
Number Width, Height, Gap, Padding, Corner Radius, Stroke Width, Opacity, Font Size… Escala de espaçamento, tokens de radius, tokens de tipografia numérica
String Conteúdo de texto Protótipos multilíngues, dados fictícios consistentes, labels de UI variantes
Boolean Visibility (visibilidade) Toggles de estados, mostrar/ocultar elementos em variantes

Collections e grupos

Variables são organizadas em Collections (coleções). Pense em uma Collection como uma "pasta raiz" — você pode ter uma Collection para cores, outra para espaçamento, outra para tipografia. Cada Collection pode ter múltiplos Modes (veremos em detalhes na próxima lição).

Dentro de uma Collection, você pode criar grupos usando a barra (/) no nome da variable: color/bg/brand cria automaticamente a hierarquia Color → bg → brand no painel.

Nomenclatura com / para criar grupos

Ao nomear uma variable spacing/component/sm, o Figma cria automaticamente a hierarquia no painel de variables. Use essa convenção para espelhar a estrutura de tokens que você projetou na lição anterior.

Passo a passo: criando sua primeira Collection de cores

Vamos criar uma Collection de cores primitivas do zero. Abra um arquivo no Figma e siga:

  1. Abra o painel de Variables. No painel direito, clique no ícone de grade na barra lateral — ou vá em Edit → Variables. O painel de Variables abre na parte esquerda da interface.
  2. Crie uma nova Collection. Clique em + Collections (ou o botão + ao lado de "Collections"). Renomeie a Collection para Primitives/Color.
  3. Adicione a primeira variable. Clique em + Variable e escolha Color. Um campo aparece para você digitar o nome e o valor. Nome: blue/50. Valor: #EEF2FF.
  4. Adicione mais cores na escala. Repita para blue/100, blue/200, blue/300, blue/400, blue/500 (sua cor primária), blue/600, blue/700, blue/800, blue/900.
  5. Crie as cores neutras. Adicione neutral/0 (#FFFFFF), neutral/50, neutral/100… neutral/900, neutral/1000 (#000000).
  6. Verifique a hierarquia. Clique no ícone de expandir ao lado de "blue" no painel — você deve ver todos os 10 tons organizados como subgrupo. O Figma criou a estrutura a partir dos nomes com /.
Atalho: duplicar variables

Clique com o botão direito em uma variable existente e escolha Duplicate Variable. Útil para criar variações dentro de um grupo sem digitar tudo do zero.

Aplicando Variables a propriedades

Com a Collection criada, você pode aplicar variables a qualquer layer:

  1. Selecione um layer. Clique em qualquer retângulo, frame ou componente no canvas.
  2. Abra o Fill. No painel direito, clique no swatch de cor no campo Fill. O color picker abre.
  3. Aplique a variable. No canto direito do color picker, clique no ícone de grid (parece quatro quadradinhos). Ele abre o painel de seleção de variables. Clique em Primitives/Color → blue → 500.
  4. Confirme a vinculação. O swatch de cor do layer agora mostra um ícone de "rhombus" (losango) indicando que está vinculado a uma variable. No Dev Mode, o token aparecerá pelo nome.

Number variables para spacing e radius

Um dos casos de uso mais valiosos das Number variables é criar uma escala de espaçamento e aplicá-la sistematicamente a todos os componentes via Auto Layout.

Crie uma nova Collection chamada Primitives/Spacing com variables do tipo Number:

  • spacing/4 → 4
  • spacing/8 → 8
  • spacing/12 → 12
  • spacing/16 → 16
  • spacing/24 → 24
  • spacing/32 → 32
  • spacing/48 → 48
  • spacing/64 → 64

Em um frame com Auto Layout, clique no campo de gap ou padding — o mesmo ícone de grid aparece para vincular o valor numérico a uma variable. Agora o espaçamento segue a escala e, se você decidir que spacing/16 deveria ser 14 px, um único clique atualiza todos os frames vinculados.

String variables para conteúdo e idioma

Crie uma Collection chamada Content/Copy com variables do tipo String:

  • cta/primary → Começar agora (modo Português)
  • cta/primary → Get started (modo English)

Aplique essa variable ao conteúdo de um botão de texto. Ao trocar o Modo do frame pai para "English", o texto do botão muda instantaneamente — sem precisar de uma cópia da tela para cada idioma. Isso é transformador para times que trabalham com produtos multilíngues.

Boolean variables para toggles

Crie uma variable Boolean chamada state/showBadge com valor true. Selecione um layer de badge em um ícone de menu e vincule a propriedade de visibilidade a essa variable. Agora, ao trocar o valor para false em um Modo, o badge desaparece em todos os frames que usam esse Modo — útil para protótipos que precisam de um estado "sem notificação" e "com notificação".

Boolean como propriedade de componente

No Figma, componentes têm Component Properties, e uma delas é Boolean. Ao vincular uma Boolean Variable a uma Component Property, você conecta o token à propriedade do componente — o valor do token pode ser sobrescrito na instância, mantendo a vinculação ao sistema de design.

Variables vs. Styles — quando usar cada um

Use Variables quando…Use Styles quando…
Precisar de Modes (temas claro/escuro, idiomas, densidades) Precisar de gradientes ou padrões de imagem em fills
O valor é primitivo (uma cor sólida, um número, uma string) O estilo é composto: sombra com múltiplas camadas, blend modes
Quiser que o token apareça pelo nome no Dev Mode / código Precisar de Text Styles com definição completa (família + peso + tamanho + entrelinha)
Espaçamento, radius, opacidade sistematizados Effects (sombras complexas, blurs) reutilizáveis sem Modes
Combinação ideal

Na prática, profissionais usam Variables para tokens de cor, espaçamento e radius (que precisam de Modes) e Text Styles + Effect Styles para definições compostas de tipografia e sombras. As duas features se complementam — você pode inclusive fazer um Text Style usar uma Variable de cor para o fill do texto.

Exemplo de uso real

Imagine o app de um banco digital com tema claro e escuro. Sem Variables, você precisaria de dois arquivos separados (ou duplicatas de cada tela). Com Variables:

  • Uma Collection Semantic/Color com Mode "Light" e Mode "Dark";
  • No Mode Light: color/bg/surface → branco; no Mode Dark: color/bg/surface → cinza escuro;
  • Todos os frames de tela têm o Mode "Light" aplicado por padrão;
  • Para ver a versão dark de qualquer tela, basta trocar o Mode do frame para "Dark" — em um segundo, a tela inteira muda.

Resultado: uma equipe de 10 designers trabalha em um único arquivo e gera as 200+ telas do app em ambos os temas sem duplicação alguma.

Resumo

  • Variables são a implementação de tokens no Figma, com quatro tipos: Color, Number, String, Boolean.
  • Collections organizam variables; grupos são criados com a barra (/) no nome.
  • Color → Fill/Stroke; Number → spacing/radius; String → conteúdo de texto; Boolean → visibilidade.
  • Number variables para spacing criam uma escala sistematizada aplicável via Auto Layout.
  • String variables permitem protótipos multilíngues trocando apenas o Mode.
  • Variables são superiores a Styles quando há necessidade de Modes; Styles ainda são melhores para gradientes e definições compostas.
✍️ Exercício

Construa sua primeira Collection de tokens

  1. Crie um arquivo Figma novo chamado "DS – Variables Fundamentos";
  2. Crie a Collection Primitives/Color com uma escala de azul (50–900) e uma escala de neutros (0–1000);
  3. Crie a Collection Primitives/Spacing com 8 values (4, 8, 12, 16, 24, 32, 48, 64);
  4. Crie a Collection Primitives/Radius com radius/sm=4, radius/md=8, radius/lg=16, radius/full=9999;
  5. Desenhe um botão com Auto Layout e vincule o gap, padding e corner radius às variables de spacing e radius.
Critério de sucesso: ao selecionar o botão, as propriedades numéricas mostram o ícone de variable vinculada. Se você mudar spacing/16 de 16 para 14, o padding do botão atualiza automaticamente.
🏆 Desafio

String variables multilíngue

Crie uma Collection Content com dois Modes: "Português" e "English". Adicione variables String para os textos principais de uma tela de login (título, subtítulo, label do campo de e-mail, label do campo de senha, texto do botão, link de "esqueci minha senha"). Monte a tela aplicando todas as Strings como variables. Alterne entre os Modes e confirme que toda a tela muda de idioma sem nenhuma duplicação.

1. Qual tipo de Variable você usaria para controlar o padding de um frame com Auto Layout de forma sistematizada?

  • Color
  • Boolean
  • String
  • Number
Variables do tipo Number podem ser vinculadas a campos numéricos como Gap, Padding, Corner Radius e Width — perfeito para criar uma escala de espaçamento sistematizada.

2. Por que variáveis de cor no Figma não substituem totalmente os Color Styles?

  • Variables de cor suportam apenas cor sólida; gradientes e padrões ainda requerem Color Styles
  • Variables não podem ser aplicadas a Fills, apenas a Strokes
  • Color Styles aparecem no Dev Mode, Variables não
  • Variables de cor só funcionam dentro de Components
Variables de cor suportam apenas valores de cor sólida (RGBA). Para gradientes, blend modes ou padrões de imagem em fills, os Color Styles continuam sendo necessários.

3. Como você cria um grupo dentro de uma Collection de Variables?

  • Clicando com o botão direito e escolhendo "Create Group"
  • Usando a barra (/) no nome da variable — ex: color/bg/brand
  • Arrastando variables para dentro de uma pasta criada separadamente
  • Usando dois pontos (:) como separador no nome
O Figma interpreta a barra (/) no nome de uma variable como separador de hierarquia e cria automaticamente os grupos correspondentes no painel.
