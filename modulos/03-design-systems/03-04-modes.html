Modes — light/dark, densidade, marca

Modes são a funcionalidade mais poderosa das Variables — eles permitem que o mesmo design mude completamente de aparência com um único clique, sem duplicar nenhuma tela.

⏱️ Leitura: ~22 min 🎯 Nível: Avançado 🛠️ Pratique no Figma

Ao final desta lição você será capaz de

  • Explicar o que são Modes dentro de uma Collection de Variables;
  • Criar um par de Modes light/dark e mapear os valores corretamente;
  • Aplicar Modes a frames e entender como a herança funciona em frames aninhados;
  • Usar Modes para casos além de cor: densidade compacto/confortável, multi-marca, multi-idioma;
  • Conhecer os limites de Modes por plano do Figma.

O que são Modes?

Dentro de uma Collection de Variables, você pode definir múltiplos Modes — cada Mode é essencialmente uma coluna de valores alternativos para todas as variables daquela Collection. Uma variable Color chamada color/bg/surface pode ter o valor #FFFFFF no Mode "Light" e #1A1E26 no Mode "Dark".

Quando você aplica um Mode a um Frame, todas as variables daquela Collection dentro do frame assumem os valores desse Mode — a troca é instantânea e afeta o frame inteiro, incluindo todos os componentes aninhados.

Analogia: planilha com colunas

Pense em uma Collection como uma planilha. Cada linha é uma variable. Cada coluna é um Mode. Para ver a versão "Dark" de uma tela, você simplesmente "ativa" a coluna Dark — o Figma lê os valores dessa coluna em todos os lugares onde as variables estão aplicadas.

Criando um par Light/Dark

Vamos criar uma Collection semântica com dois Modes. Este é o fluxo de trabalho padrão para dark mode no Figma:

  1. Crie uma nova Collection. No painel de Variables, clique em + Collection. Renomeie para Semantic/Color.
  2. Renomeie o Mode padrão. Por padrão, a Collection tem um Mode chamado "Value". Clique duas vezes nele e renomeie para Light.
  3. Adicione o segundo Mode. Clique no ícone de + ao lado dos Modes (no cabeçalho do painel) para adicionar um novo Mode. Renomeie para Dark.
  4. Adicione as variables semânticas. Crie color/bg/surface. Para o Mode Light, defina o valor como #FFFFFF (ou vincule ao primitivo neutral/0). Para o Mode Dark, defina como #1A1E26 (ou primitivo neutral/950).
  5. Continue com as demais variables. color/bg/subtle, color/text/default, color/text/muted, color/border/default, color/bg/brand, color/feedback/danger — cada uma com valores diferentes para Light e Dark.
  6. Aplique o Mode a um Frame. Selecione um Frame no canvas. No painel direito, role até a seção Variables. Você verá as Collections disponíveis. Clique em Semantic/Color e selecione o Mode que deseja aplicar a esse Frame.
  7. Alterne entre os Modes. Selecione o Frame, troque de "Light" para "Dark" no painel. O design inteiro muda instantaneamente.

Uma Collection com Modes Light e Dark. Cada variable tem dois valores — um por Mode.

Herança de Modes em frames aninhados

Quando você aplica um Mode a um Frame pai, todos os frames filhos herdam esse Mode automaticamente. Você não precisa aplicar o Mode em cada elemento individualmente.

No entanto, você pode sobrescrever o Mode em um frame filho — por exemplo, ter a tela principal em Light Mode mas um modal específico sempre em Dark Mode para criar um efeito visual específico. O frame filho com o Mode sobrescrito ignora o valor herdado do pai.

Herança funciona apenas para Collections ativas

A herança de Mode acontece somente para a Collection que você aplicou ao frame pai. Se um frame filho usa variables de uma Collection diferente (ex: Semantic vs. Brand), cada Collection precisa ter seu Mode definido ou herdado separadamente.

Casos de uso além de Light/Dark

Modes não são apenas para temas de cor. Qualquer dimensão de variação que o seu produto precise pode ser modelada com Modes:

Densidade: Compacto e Confortável

Crie uma Collection Semantic/Spacing com Modes "Comfortable" e "Compact". No Mode Comfortable, spacing/component/md vale 16. No Mode Compact, vale 12. Aplique o Mode Compact em um frame para ver toda a interface comprimida — útil para dashboards com muito dado onde o usuário escolhe a densidade de informação.

Multi-marca (White Label)

Empresas que vendem software white-label para múltiplos clientes podem ter um Mode por cliente. A marca A usa roxo, a marca B usa azul petróleo, a marca C usa verde — cada uma é um Mode da Collection Brand/Color. Um único arquivo Figma, três marcas, sem duplicação.

Multi-idioma

Crie uma Collection Content/Copy com Modes "pt-BR", "en-US" e "es-MX". Cada variable String tem o texto na língua correspondente. Ao trocar o Mode do frame, toda a interface muda de idioma — perfeito para apresentar um produto para um cliente internacional.

Limites de Modes por plano

O Figma limita o número de Modes por Collection de acordo com o plano:

  • Starter (gratuito): 1 Mode por Collection (sem alternância real de tema);
  • Professional: até 4 Modes por Collection;
  • Organization / Enterprise: Modes ilimitados por Collection.
Estratégia para planos limitados

Se você tem apenas 4 Modes disponíveis, priorize os mais críticos: Light e Dark são quase sempre os primeiros. Os outros dois podem ser, por exemplo, dois idiomas ou duas densidades, dependendo das necessidades do produto.

Exemplo de uso real: dark mode em 3 passos

Imagine que você já tem uma tela de login completamente montada com variables semânticas de cor aplicadas. Para criar o dark mode:

  1. Adicione o Mode "Dark" na Collection Semantic/Color;
  2. Preencha os valores Dark de cada variable (bg/surface → #1A1E26, text/default → #E8EAEE, etc.) — 10 a 15 variáveis no total;
  3. Selecione o Frame da tela e troque o Mode para "Dark" no painel direito.

A tela inteira — todos os inputs, botões, texto, backgrounds — muda para dark mode instantaneamente. Zero retrabalho em componentes.

Resumo

  • Modes são colunas de valores alternativos dentro de uma Collection — uma variable tem um valor diferente para cada Mode.
  • Aplicar um Mode a um Frame muda instantaneamente todos os elementos que usam variables daquela Collection.
  • Frames filhos herdam o Mode do pai; é possível sobrescrever em frames específicos.
  • Modes servem para: light/dark, densidade, multi-marca, multi-idioma, multi-plataforma.
  • O limite de Modes depende do plano: 1 (Starter), 4 (Professional), ilimitado (Organization+).
✍️ Exercício

Implemente o dark mode em uma tela existente

  1. Crie uma tela simples (card de produto ou tela de login) usando apenas variables da Collection Semantic/Color no Mode Light;
  2. Adicione o Mode Dark à Collection e preencha os valores invertidos para cada variable;
  3. Selecione o Frame da tela e troque para o Mode Dark;
  4. Ajuste os valores até a versão dark estar bem contrastada e legível (use pelo menos razão de contraste 4.5:1 para texto).
Critério de sucesso: a mesma tela funciona nos dois Modes sem nenhuma duplicação de frames e sem nenhum valor de cor "hardcoded" (tudo via variables).

QuizTeste seu conhecimento

1. O que acontece com os frames filhos quando você aplica um Mode a um frame pai?

  • Nada — Modes só afetam o frame ao qual são aplicados diretamente
  • Os frames filhos recebem o Mode oposto automaticamente para criar contraste
  • Os frames filhos herdam o Mode do pai, a menos que tenham um Mode sobrescrito explicitamente
  • Os frames filhos precisam ser selecionados manualmente para receber o Mode
Modes são herdados em cascata: um frame filho recebe o Mode do pai automaticamente. Mas você pode sobrescrever o Mode em qualquer frame filho para criar exceções localizadas.

2. Qual plano do Figma permite usar Modes ilimitados por Collection?

  • Organization ou Enterprise
  • Professional
  • Starter (gratuito)
  • Qualquer plano pago
Apenas os planos Organization e Enterprise têm Modes ilimitados. O Professional é limitado a 4 Modes por Collection; o Starter a apenas 1 (sem alternância real de tema).

3. Além de light/dark, qual outro caso de uso de Modes é mencionado na lição?

  • Animações de transição entre estados
  • Densidade de espaçamento (Comfortable/Compact) para interfaces com mais ou menos informação
  • Versionamento histórico de mudanças de design
  • Diferentes resoluções de exportação (1x, 2x, 3x)
Modes de densidade permitem ter uma interface compacta (menos padding) e uma confortável (mais padding) a partir da mesma estrutura de componentes — muito útil em dashboards e aplicações enterprise.
