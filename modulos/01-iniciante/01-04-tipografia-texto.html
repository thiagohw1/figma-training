Tipografia e a ferramenta de texto

Mais de 90% do conteúdo de uma interface é texto. Dominar tipografia no Figma não é opcional — é o que dá hierarquia, ritmo e clareza a qualquer design.

⏱️ Leitura: ~22 min 🎯 Nível: Iniciante 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Usar a ferramenta Texto e seus três modos de dimensionamento;
  • Configurar família, peso, tamanho, line-height, letter-spacing e alinhamento;
  • Aplicar decoração, truncamento e listas ao texto;
  • Usar fontes do Google Fonts e fontes locais no Figma;
  • Montar uma escala tipográfica básica aplicando princípios de hierarquia.

A ferramenta Texto

Pressione T para ativar a ferramenta de texto. Você tem dois modos de criação:

  • Clique simples: cria um texto de Auto Width — o campo cresce horizontalmente conforme você digita. Bom para títulos e labels curtos.
  • Clique e arraste: cria um texto de Fixed Width com a largura que você definiu — o texto quebra de linha automaticamente. Bom para parágrafos e textos longos.

Três modos de dimensionamento

Com o texto selecionado, no painel direito você encontra o ícone de redimensionamento. São 3 modos:

ModoComportamentoQuando usar
Auto WidthW e H crescem com o conteúdo; o texto nunca quebra linhaTítulos, botões, labels de uma linha
Auto HeightW é fixo (você define); H cresce conforme linhas aumentamParágrafos com largura definida pelo layout
Fixed SizeW e H são fixos; conteúdo excedente fica invisívelQuando você precisa de uma caixa exata; use truncation

Propriedades tipográficas no Figma

Família e peso (Font Family e Weight)

O campo de fonte no topo do painel de texto. Digite o nome da família para buscar. O Figma carrega automaticamente todas as fontes disponíveis no Google Fonts — mais de 1.400 famílias. O campo de peso lista os variants disponíveis: Thin (100), Light (300), Regular (400), Medium (500), SemiBold (600), Bold (700), ExtraBold (800), Black (900). Nem todas as famílias têm todos os pesos.

Tamanho e escala

O campo de tamanho (Font Size) é em pixels. Para UI digital, os tamanhos mais comuns são:

  • 12–13 px: captions, labels secundários, timestamps;
  • 14–15 px: texto de suporte, corpo secundário;
  • 16 px: corpo de texto principal (tamanho padrão do browser);
  • 18–20 px: texto de destaque, leads;
  • 24–32 px: subtítulos, títulos de cards;
  • 40–64 px: títulos de seção, hero headings;
  • 72–96+ px: display, headings heroicos.

Line Height (altura de linha)

A distância vertical entre as linhas de texto. No Figma, você pode definir em pixels ou em porcentagem relativa ao tamanho. Diretrizes gerais:

  • Textos grandes (títulos): line-height de 1.1 a 1.3 (110–130%);
  • Textos de corpo: line-height de 1.5 a 1.6 (150–160%);
  • Captions: line-height de 1.3 a 1.4.

Letter Spacing (espaçamento entre letras)

Também chamado de tracking. No Figma, em pixels ou percentagem. Regras práticas:

  • Textos pequenos (caps, labels): adicione um letter-spacing positivo (5–10%) para melhorar a legibilidade;
  • Textos de corpo: 0 ou levemente negativo (−1%);
  • Títulos grandes (36px+): letter-spacing negativo (−2% a −4%) melhora o impacto visual.

Alinhamento

Horizontal: esquerda, centro, direita e justificado. Vertical (em Fixed Size): topo, meio e base. Use alinhamento justificado com cuidado — funciona bem em print, mas pode criar espaços irregulares em layouts digitais responsivos.

Decoração e transformação

  • Underline / Strikethrough: sublinhado e tachado, respectivamente;
  • Uppercase / Lowercase / Capitalize: no painel de texto, seção "Transform";
  • Superscript / Subscript: para notas de rodapé e fórmulas.

Listas

O Figma suporta listas com marcadores (bulleted list) e numeradas (ordered list) diretamente no painel de texto. Clique nos ícones de lista no painel direito, com o cursor dentro do campo de texto.

Truncation (truncamento)

Em modo Fixed Size, o Figma permite ativar o Truncate text — o texto excedente é cortado com "…" (ellipsis). Isso simula exatamente o comportamento de text-overflow: ellipsis no CSS, essencial para cards, listas e qualquer UI com texto dinâmico. Ative nas opções avançadas de texto no painel direito.

Cuidado com texto em Auto Width em componentes

Se você criar um botão com texto em Auto Width dentro de um Frame e o texto crescer, o Frame pai não vai crescer junto a menos que tenha Auto Layout ativado. Para componentes de botão reutilizáveis, sempre use Auto Layout + texto em Auto Width.

Fontes no Figma

Google Fonts (nativas)

O Figma integra todas as fontes do Google Fonts sem necessidade de instalação. Você pode usar Inter, Roboto, Poppins, DM Sans, Plus Jakarta Sans e milhares de outras diretamente. Apenas pesquise o nome no campo de família.

Fontes locais (desktop app)

Se você usar o Figma Desktop App (não o browser), ele detecta automaticamente todas as fontes instaladas no seu sistema operacional. Fontes da Adobe Fonts, fontes pagas ou fontes personalizadas da marca aparecem na lista quando instaladas localmente.

Fontes compartilhadas em projetos de time

Quando você abre um arquivo com fontes que não estão no Google Fonts e não estão instaladas localmente, o Figma mostra um aviso "Missing fonts". Cada membro do time precisa ter a fonte instalada para visualizá-la corretamente. Para projetos corporativos, use sempre fontes do Google Fonts ou distribua os arquivos de fonte para o time.

Fontes recomendadas para UI em 2025

Interface: Inter, DM Sans, Plus Jakarta Sans. Display: Instrument Serif, Clash Display. Monospace: JetBrains Mono, Fira Code. Todas no Google Fonts, gratuitas e com suporte a múltiplos pesos.

Fundamentos de tipografia para design

Escala tipográfica

Uma escala tipográfica é um conjunto predefinido de tamanhos que formam uma progressão harmônica. A escala mais usada em UI é baseada em uma razão de 1.25 (Major Third):

Escala tipográfica simples: 6 tamanhos, 2 pesos — suficiente para a maioria dos apps.

Hierarquia tipográfica

Hierarquia é o que guia o olhar do usuário. Você cria hierarquia com quatro ferramentas:

  1. Tamanho: elementos maiores chamam mais atenção;
  2. Peso: Bold/SemiBold se destaca sobre Regular;
  3. Cor: cor primária ou texto escuro para informação principal; --text-muted para informação secundária;
  4. Espaçamento: mais espaço acima de um título reforça sua importância.

Legibilidade

Regras práticas para texto legível em telas:

  • Comprimento ideal de linha: 50–75 caracteres por linha;
  • Contraste mínimo WCAG AA: 4.5:1 para texto normal, 3:1 para texto grande;
  • Evite texto sobre fundos muito complexos sem overlay de cor;
  • Tamanho mínimo legível em mobile: 12 px (14 px recomendado).

Exemplo de uso real: montando uma escala tipográfica

Vamos criar um guia de estilos tipográficos básico:

  1. Crie um Frame de 600×700 px. Renomeie para "Type Scale – Inter". Dê um fill de fundo claro (#F5F6F8).
  2. Crie o Display. Ferramenta T, clique dentro do Frame. Digite "O design começa aqui". Família: Inter, Peso: Bold (700), Tamanho: 40 px. Letter-spacing: -1 px. Posicione no topo com 40 px de margem.
  3. Adicione os demais níveis. Crie mais 4 textos com as seguintes configurações: H1 (28px, SemiBold), H2 (22px, SemiBold), Body (16px, Regular, line-height 24px), Caption (13px, Regular, cor #5B6573).
  4. Alinhe e distribua. Selecione todos os textos. Use o painel de alinhamento: alinhe à esquerda. Distribua verticalmente com espaçamento uniforme.
  5. Salve como Text Styles. Selecione o texto H1. No painel direito, seção Text, clique em + ao lado de "Text Styles". Nomeie "Heading/H1". Repita para cada nível. Agora você tem estilos reutilizáveis.

Resumo

  • A ferramenta Texto (T) tem 3 modos: Auto Width, Auto Height e Fixed Size.
  • As propriedades tipográficas fundamentais são família, peso, tamanho, line-height, letter-spacing e alinhamento.
  • Truncation (text-overflow: ellipsis) funciona apenas em modo Fixed Size.
  • O Figma carrega automaticamente todas as fontes do Google Fonts; fontes locais aparecem via desktop app.
  • Uma escala tipográfica com 5–6 tamanhos e 2 pesos é suficiente para a maioria dos apps.
  • Hierarquia tipográfica é criada com tamanho, peso, cor e espaçamento.
✍️ Exercício

Monte a escala tipográfica da sua marca

  1. Crie um Frame de 640×800 px chamado "Type System".
  2. Escolha uma família do Google Fonts (sugestão: "Plus Jakarta Sans" ou "DM Sans").
  3. Crie 6 camadas de texto com os seguintes níveis: Display (40px/700), H1 (30px/700), H2 (22px/600), H3 (18px/600), Body (16px/400, line-height 1.6), Caption (13px/400, cor secondary).
  4. Salve cada um como Text Style (+ no painel de texto).
  5. Crie um card simples ao lado com título, subtítulo e parágrafo usando os Text Styles que você criou.
Critério de sucesso: o painel de Text Styles do arquivo mostra todos os 6 estilos nomeados; o card usa apenas estilos da escala, sem valores customizados avulsos.
🏆 Desafio

Landing page hero com tipografia expressiva

Crie um Frame Desktop (1440×900 px) com uma seção hero completa: headline de impacto em Display (~72 px, Bold, letter-spacing negativo), subtítulo em H2, parágrafo body, e dois botões. A tipografia deve contar uma história — o tamanho e peso deve guiar o olho do headline para o CTA. Use apenas 1 família tipográfica com variações de peso. Bônus: experimente misturar uma fonte Serif para o headline e uma Sans para o corpo.

QuizTeste seu conhecimento

1. Em qual modo de dimensionamento o texto nunca quebra linha e a caixa cresce conforme você digita?

  • Fixed Size
  • Auto Height
  • Auto Width
  • Clip Content
No modo Auto Width, o campo de texto cresce horizontalmente para acomodar todo o conteúdo em uma única linha — ideal para títulos e labels que nunca devem quebrar.

2. Qual line-height é recomendado para texto de corpo (16px) em interfaces digitais?

  • 1.0 (sem espaço extra)
  • 1.5 a 1.6
  • 2.0
  • 0.8
Para texto de corpo em telas, um line-height de 1.5 a 1.6 (150–160%) é o ideal para legibilidade. Menos que isso comprime as linhas; mais cria um ritmo muito espaçado.

3. Para títulos grandes (36px+), qual ajuste de letter-spacing geralmente melhora o impacto visual?

  • Letter-spacing negativo (−2% a −4%)
  • Letter-spacing positivo (+10%)
  • Letter-spacing zero
  • Não faz diferença para títulos grandes
Títulos grandes com letter-spacing negativo ficam mais compactos e com mais impacto visual — exatamente como fazem as grandes marcas e sistemas de design modernos (Apple, Google, etc.).
