Imagens, máscaras, crop e exportação

Saber trabalhar com imagens — inserir, recortar, mascarar e exportar com qualidade — é uma habilidade diária em qualquer projeto de UI ou branding no Figma.

⏱️ Leitura: ~18 min 🎯 Nível: Iniciante 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Inserir imagens de múltiplas formas no Figma (Place image, arrastar, fill);
  • Ajustar o modo de preenchimento: Fill, Fit, Crop e Tile;
  • Criar máscaras para recortar imagens em qualquer forma;
  • Exportar assets em PNG, JPG, SVG e PDF com as escalas corretas;
  • Criar um avatar circular com máscara.

Inserindo imagens no Figma

Há três formas principais de adicionar uma imagem ao seu arquivo:

1. Place image (Ctrl/⌘ + Shift + K)

O método mais eficiente. Pressione Ctrl/⌘ + Shift + K, selecione um ou mais arquivos de imagem. Ao selecionar múltiplas imagens, o Figma entra em modo de "stamp" — clique uma vez para cada imagem ou arraste para definir o tamanho. A imagem é inserida como um retângulo com fill de imagem.

2. Arrastar do desktop

Simplesmente arraste um arquivo de imagem (.jpg, .png, .webp, .gif, .svg) do seu explorador de arquivos diretamente para o canvas do Figma. O Figma cria automaticamente um retângulo com a imagem como fill. Para substituir uma imagem existente, segure Alt/⌥ ao soltar — a imagem nova substitui a existente mantendo a forma e dimensões.

3. Colar do clipboard

Copie uma imagem de qualquer lugar (browser, Photoshop, visualizador de imagens) e cole diretamente no Figma com Ctrl/⌘ + V.

Formatos suportados

O Figma suporta JPG, PNG, GIF, WebP, BMP, ICO e SVG. Arquivos SVG importados são vetorizados e editáveis como shapes. Para PSD, AI ou outros formatos proprietários, você precisa exportar para um formato suportado antes.

Modos de preenchimento de imagem

Quando uma imagem é usada como fill de uma forma, você controla como ela se encaixa no container. Com a forma selecionada, clique no swatch de fill da imagem e veja os 4 modos:

ModoComportamentoEquivalente CSS
FillPreenche todo o espaço; corta o que não cabe. A imagem mantém proporçõesobject-fit: cover
FitA imagem inteira fica visível dentro da forma; pode ter espaço vazioobject-fit: contain
CropVocê reposiciona e escala a imagem manualmente dentro da formaobject-fit: none + object-position
TileA imagem se repete em mosaico; você controla o tamanho de cada tilebackground-repeat: repeat

Modo Crop na prática

Clique no swatch de fill da imagem, selecione Crop. Um contorno tracejado aparece na forma. Você pode:

  • Arrastar a imagem para reposicionar o enquadramento;
  • Arrastar as alças para escalar a imagem dentro da forma;
  • Pressionar Enter para confirmar o recorte.

Máscaras (Use as Mask)

Uma máscara no Figma usa a forma de um elemento para recortar os elementos acima dele na pilha de layers. A forma da máscara define o que é visível: tudo dentro da forma aparece, tudo fora fica oculto.

Como criar uma máscara

  1. Coloque a forma de máscara abaixo da imagem na pilha de layers (ou selecione primeiro);
  2. Selecione a forma de máscara;
  3. Clique com botão direito → Use as Mask (ou use o atalho Ctrl/⌘ + Alt/⌥ + M).

Uma máscara agrupa automaticamente a forma e os elementos acima em um Mask Group. A forma perde seu fill (fica transparente visualmente) e passa a definir apenas o contorno do recorte.

A ordem importa nas máscaras

A forma de máscara deve ser o elemento mais abaixo na seleção (ou no grupo). O elemento que você quer mascarar deve estar acima da forma no painel de layers. Lembre: no Figma, "mais acima" no painel = visualmente na frente.

Passo a passo: avatar circular com máscara

Vamos criar um avatar de perfil redondo — um dos usos mais comuns de máscaras em UI:

  1. Insira uma foto. Pressione Ctrl/⌘ + Shift + K e selecione uma foto de rosto. Ou use um placeholder: crie um retângulo e adicione uma imagem como fill.
  2. Crie o círculo de máscara. Com O, segurando Shift, desenhe um círculo perfeito sobre a foto. Tamanho: 80×80 px (padrão para avatares pequenos) ou 120×120 px (médio).
  3. Posicione o círculo sobre a foto. No painel de layers, garanta que o círculo está abaixo da imagem. Se estiver acima, pressione Ctrl/⌘ + [ para mover para baixo.
  4. Selecione ambos. Selecione o círculo e a imagem (ou selecione só o círculo se ele estiver logo abaixo da imagem no grupo).
  5. Aplique a máscara. Clique com botão direito → Use as Mask. Ou pressione Ctrl/⌘ + Alt + M. A foto agora está recortada em círculo!
  6. Adicione o stroke de borda. Selecione o Mask Group. Adicione uma elipse por cima (mesmo tamanho, 80×80 px), sem fill, com stroke branco de 2 px. Isso simula a borda do avatar.

Exportação de assets

A exportação no Figma é flexível e poderosa. Selecione qualquer elemento (layer, frame, grupo) e use o painel de Export na parte inferior do painel direito.

Formatos disponíveis

FormatoMelhor paraObservação
PNGÍcones, assets com transparência, screenshotsSuporta canal alpha (transparência)
JPGFotos, banners sem transparênciaCompressão com perda; sem alpha
SVGÍcones, logos, ilustrações vetoriaisEscalável; arquivo de texto (XML)
PDFApresentações, documentos, printVetorial, suporte a múltiplas páginas
WebPWeb moderna — compressão superiorDisponível via plugin

Escalas de exportação (@1x, @2x, @3x)

Para apps mobile, você precisa exportar em múltiplas resoluções para suportar telas de alta densidade (Retina, OLED):

  • @1x: tamanho nativo (ex: 24×24 px) — para telas 1:1;
  • @2x: 48×48 px — para telas Retina (iPhone padrão, Android hdpi);
  • @3x: 72×72 px — para telas super Retina (iPhone Pro, Android xxxhdpi).

No painel de Export, clique em + para adicionar múltiplos exports de uma vez. O Figma vai gerar um arquivo nomeado automaticamente: icon@2x.png, icon@3x.png.

Export Settings e Slices

Para projetos grandes, use Export Settings na seção de configurações do arquivo para exportar todos os assets de uma vez. Os Slices (ferramenta de fatia) permitem definir áreas personalizadas de exportação independentes dos elementos — úteis quando você quer exportar um recorte específico do design.

Boas práticas de assets

1. Sempre exporte ícones como SVG para web — escalabilidade infinita sem pixelação. 2. Para apps iOS, exporte PNG em @2x e @3x. Para Android, exporte para as pastas de density (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi). 3. Nomeie os frames de export com o nome final do asset: "icon-home" exportará "icon-home.svg".

Dica: marcar layers para export

Você pode definir Export Settings diretamente nos layers durante o design e não apenas na hora de exportar. Assim, quando o desenvolvedor abre o Dev Mode, os assets já aparecem marcados para exportação com as escalas corretas — sem precisar de briefing extra.

Exemplo de uso real

Em um card de artigo de blog, você vai usar as técnicas desta lição assim:

  • Imagem de capa: retângulo 400×200 px, fill de imagem em modo Fill (cover), recortando a parte que não cabe;
  • Avatar do autor: elipse 40×40 px com máscara da foto do autor;
  • Exportação: o card inteiro exportado como PNG @2x para preview; a thumbnail exportada como JPG para o website; os ícones como SVG.

Resumo

  • Imagens são inseridas via Ctrl/⌘ + Shift + K, arrastar do desktop ou colar.
  • Modos de fill: Fill (cover), Fit (contain), Crop (manual) e Tile (mosaico).
  • Máscara (Ctrl/⌘ + Alt + M) usa a forma de um elemento para recortar os elementos acima.
  • A forma de máscara deve estar abaixo dos elementos mascarados na pilha de layers.
  • Exportação suporta PNG, JPG, SVG, PDF; escalas @1x/@2x/@3x para mobile.
  • Defina Export Settings durante o design para facilitar o handoff com desenvolvedores.
✍️ Exercício

Crie um card de perfil de usuário

  1. Crie um Frame de 320×100 px, fill branco, corner radius 12 px, sombra suave.
  2. Insira uma imagem de placeholder e crie um avatar circular de 56×56 px usando máscara (elipse + imagem).
  3. Ao lado do avatar, adicione o nome do usuário (16px/600) e um subtítulo (13px/400, cor muted).
  4. Adicione um botão de "Seguir" no lado direito do card (texto + stroke).
  5. Configure o Frame para exportar como PNG @2x e SVG. (Seção Export no painel direito.)
Critério de sucesso: o avatar é perfeitamente circular; o painel de Export do Frame mostra dois exports configurados (@2x PNG e SVG).
🏆 Desafio

Galeria de avatares em formas diversas

Crie um Frame com 5 versões do mesmo avatar, cada um recortado em uma forma diferente usando máscara: círculo, hexágono (polígono 6 lados), quadrado com corner radius 50%, estrela de 5 pontas, e um losango (quadrado rotacionado 45°). Todos devem ter exatamente 80×80 px de bounding box e a mesma foto como fill. Isso demonstra o poder das máscaras para criar identidades visuais diversas.

QuizTeste seu conhecimento

1. No modo Fill de imagem, o que acontece quando a imagem tem proporções diferentes da forma?

  • A imagem é esticada para preencher a forma
  • A imagem fica inteira dentro da forma com espaço em branco
  • A imagem se repete em mosaico
  • A imagem mantém proporções e o excesso é cortado (como CSS cover)
O modo Fill preenche todo o espaço da forma mantendo as proporções da imagem — o que não cabe é cortado. É o equivalente ao object-fit: cover do CSS.

2. Para criar um avatar circular, qual deve ser a posição da forma de máscara (elipse) na pilha de layers?

  • Abaixo da imagem (mais baixo no painel de layers)
  • Acima da imagem (mais alto no painel de layers)
  • Em uma página separada
  • A ordem não importa
A forma de máscara deve estar abaixo dos elementos que ela vai mascarar no painel de layers. No Figma, "mais abaixo" no painel = visualmente atrás. A máscara define o contorno, e os elementos acima dela ficam recortados à sua forma.

3. Para exportar ícones para a web com qualidade perfeita em qualquer resolução de tela, qual formato é mais recomendado?

  • PNG @3x
  • SVG
  • JPG @2x
  • PDF
SVG é vetorial — escala infinitamente sem pixelação. É o formato ideal para ícones na web porque é leve, escalável e pode ser estilizado com CSS. PNG @3x é uma boa alternativa para browsers que não suportam SVG, mas o SVG é superior para ícones.
