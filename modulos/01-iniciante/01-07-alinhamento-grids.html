Alinhamento, distribuição e Layout Grids

O que diferencia um design feito no olho de um feito com precisão? Alinhamento rigoroso, distribuição consistente e um grid sólido como base. É aqui que a interface ganha ritmo e coerência.

⏱️ Leitura: ~20 min 🎯 Nível: Iniciante 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Alinhar elementos pelos 6 eixos (esquerda, centro, direita, topo, meio, base);
  • Distribuir elementos com espaçamento uniforme;
  • Usar Smart Selection e Tidy Up para organizar grupos de elementos;
  • Criar e configurar Layout Grids (Columns, Rows e Grid);
  • Aplicar o grid de 8pt para espaçamentos consistentes.

Ferramentas de alinhamento

Selecione dois ou mais elementos e o painel direito mostra a barra de alinhamento com 6 botões. Para um único elemento, o alinhamento é relativo ao Frame pai; para múltiplos elementos, é relativo ao bounding box da seleção (ou a um elemento de referência).

Alinhar pela seleção ou pelo frame

Por padrão, os botões de alinhamento alinham em relação à seleção inteira (bounding box de todos os selecionados). Para alinhar dentro do Frame pai, use a opção no dropdown do ícone de alinhamento: Align to frame ou Align to selection. Você também pode segurar um elemento específico como "âncora" clicando nele com Alt/⌥ — ele fica fixo e os demais se movem para se alinhar com ele.

Distribuição

Além de alinhar, você pode distribuir elementos com espaçamento uniforme. Os dois botões de distribuição (ao lado dos de alinhamento):

  • Distribute Horizontal Spacing: distribui os elementos horizontalmente com o mesmo espaço entre eles;
  • Distribute Vertical Spacing: distribui verticalmente.

O Figma calcula automaticamente o espaçamento com base no espaço disponível entre o primeiro e o último elemento da seleção. Se você quiser espaçamento específico, use o campo de spacing que aparece ao selecionar múltiplos elementos.

Smart Selection e Tidy Up

Quando você seleciona múltiplos elementos, o Figma ativa a Smart Selection: handles cor-de-rosa aparecem entre os elementos, mostrando o espaçamento atual. Você pode arrastar esses handles para ajustar o gap entre todos de uma vez.

O botão Tidy Up (ícone de grade no painel, ou via botão direito) reorganiza automaticamente elementos selecionados em uma grade regular, espaçando-os uniformemente tanto horizontal quanto verticalmente. É ideal para ícones, cards e qualquer elemento repetido.

Tidy Up: o atalho secreto

Selecione vários elementos desordenados e pressione Tidy Up no painel direito. Em segundos, eles se organizam numa grade perfeita. Se os elementos têm tamanhos diferentes, o Figma os centraliza no grid. Economiza minutos de ajuste manual.

Layout Grids

Um Layout Grid é uma grade visual sobreposta a um Frame para guiar o posicionamento dos elementos. Ele é visível durante o design mas não exportado. Pense nele como as linhas de caderno — você vê enquanto escreve, mas não aparecem no resultado final.

Tipos de Layout Grid

Com um Frame selecionado, clique em + na seção "Layout grid" do painel direito:

TipoPara que servePropriedades
GridQuadrícula uniforme (útil para ícones e espaçamento 8pt)Tamanho do grid, cor, opacidade
ColumnsColunas verticais (padrão para layout de página)Count, Type (stretch/left/center/right), Width, Margin, Gutter
RowsLinhas horizontais (baseline grid para tipografia)Count, Type, Height, Margin, Gutter

O grid de colunas — configuração padrão

Para uma página web de 1440 px de largura, o grid padrão da indústria é:

  • 12 colunas (ou 6 para simplificar);
  • Gutter (espaço entre colunas): 24 px;
  • Margin (espaço nas bordas): 80 px (ou 160 px para conteúdo centrado);
  • Type: Stretch — as colunas preenchem o espaço disponível.

Para mobile (390 px), use 4 colunas, 16 px de gutter e 16 px de margin.

Diagrama: grid de 12 colunas

Grid de 12 colunas: margins laterais (laranja) + colunas (roxo) + gutters (espaço entre colunas).

O sistema de 8pt

O grid de 8pt (ou 8px) é um sistema de espaçamento onde todos os valores de padding, margin, gap e tamanho são múltiplos de 8: 8, 16, 24, 32, 40, 48, 64, 80, 96… O benefício é triplo:

  • Consistência visual: todos os espaçamentos do design estão em harmonia;
  • Facilidade de handoff: developers adoram valores de grid — são fáceis de traduzir para código;
  • Compatibilidade com telas HiDPI: múltiplos de 8 se dividem perfeitamente em @2x e @3x sem valores fracionários.

Para casos onde 8 px é muito, use múltiplos de 4 (4, 8, 12, 16…). Para micros espaçamentos em ícones, use múltiplos de 2.

Baseline grid

O Baseline Grid é um grid de linhas horizontais no intervalo do line-height do texto de corpo (ex: 8 px ou 4 px). Ele garante que textos de diferentes tamanhos se alinhem na mesma linha de base, criando ritmo vertical consistente — como nas linhas de um caderno. Configure um Layout Grid de Rows com Height igual ao seu line-height (ex: 8 px).

Passo a passo: aplicar um grid de colunas

  1. Crie um Frame de Desktop. Pressione F e selecione o preset "Desktop" (1440×1024 px). Renomeie para "Home – Desktop".
  2. Adicione um Layout Grid de colunas. Com o Frame selecionado, no painel direito, clique em + na seção Layout Grid. O Figma adiciona um grid uniforme por padrão.
  3. Configure como Columns. Clique no ícone do grid para abrir as opções. Mude o tipo para Columns. Configure: Count: 12, Type: Stretch, Gutter: 24, Margin: 80.
  4. Ajuste a cor e visibilidade. Clique no swatch de cor do grid. Use vermelho (#FF0000) com 10% de opacidade — o rosa suave é o padrão da indústria para guias visuais. Pressione Ctrl/⌘ + Shift + 4 para mostrar/ocultar os grids a qualquer momento.
  5. Adicione elementos dentro do grid. Crie um header que ocupe toda a largura (de margin a margin). Crie 3 cards que ocupem 4 colunas cada (em 12 colunas, 3 × 4 = 12). Os elementos devem se encaixar perfeitamente nas colunas.

Resumo

  • Os 6 botões de alinhamento alinham seleções pela borda ou centro em ambos os eixos.
  • Distribuição cria espaçamento uniforme entre elementos; Smart Selection permite ajustar o gap interativamente.
  • Tidy Up organiza elementos em grade automaticamente.
  • Layout Grids (Columns, Rows, Grid) são guias visuais não exportadas que garantem consistência de layout.
  • Para web: 12 colunas, 24px gutter, 80px margin. Para mobile: 4 colunas, 16px gutter, 16px margin.
  • O grid de 8pt garante espaçamentos harmônicos e compatíveis com múltiplas resoluções.
✍️ Exercício

Layout de cards com grid de colunas

  1. Crie um Frame Desktop (1440×900 px).
  2. Adicione um Layout Grid de 12 colunas (Gutter: 24, Margin: 80, Type: Stretch).
  3. Crie um header que ocupe as 12 colunas (span 12), altura 72 px.
  4. Crie 4 cards abaixo do header, cada um ocupando 3 colunas (span 3), com 240 px de altura.
  5. Certifique-se de que as bordas dos cards se alinham às bordas das colunas do grid.
  6. Use o alinhamento e distribuição para garantir que os 4 cards tenham o mesmo espaço entre eles (gutter do grid = 24 px).
Critério de sucesso: os cards se encaixam perfeitamente nas colunas do grid; ao mostrar o Layout Grid (Ctrl/⌘ + Shift + 4), as bordas dos cards coincidem com as colunas.
🏆 Desafio

Sistema de spacing com grid de 8pt

Crie um Frame de 600×800 px chamado "Spacing System". Nele, documente visualmente o seu sistema de spacing: crie swatches visuais para cada valor do grid de 8pt (4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96 px). Cada swatch é um retângulo cujo tamanho representa o valor (ex: um retângulo de 4 px de altura para o valor 4 px), com um label ao lado. Adicione um Layout Grid de 8 px uniforme ao Frame para visualizar como os swatches se encaixam no grid. Este é o começo de um Style Guide real.

QuizTeste seu conhecimento

1. Qual configuração de Layout Grid é mais usada para layout de página desktop?

  • Grid uniforme de 8px
  • Columns com 12 colunas, Stretch, Gutter 24px, Margin 80px
  • Rows com 6 linhas, Height 80px
  • Grid uniforme de 64px
O padrão da indústria para desktop é 12 colunas com Stretch, gutter de 24 px e margens laterais de 80 px. Isso permite layouts flexíveis: 1, 2, 3, 4 ou 6 colunas de conteúdo.

2. O que o recurso "Tidy Up" faz no Figma?

  • Apaga layers sem nome
  • Alinha todos os elementos à borda esquerda do frame
  • Reorganiza automaticamente os elementos selecionados em uma grade com espaçamento uniforme
  • Converte groups em frames
Tidy Up reorganiza elementos selecionados em uma grade regular, distribuindo-os uniformemente tanto horizontal quanto verticalmente — perfeito para ícones, cards e listas desordenadas.

3. Por que o grid de 8pt é amplamente adotado em UI design?

  • Porque 8 é o número da sorte no design
  • Porque facilita o uso de frações de pixel
  • Porque é o padrão do CSS Grid
  • Porque garante espaçamentos harmônicos, facilita o handoff e se divide perfeitamente em telas @2x e @3x
O grid de 8pt produz valores que escalam perfeitamente para telas de alta densidade (8 × 2 = 16, 8 × 3 = 24, sem valores fracionários), garante consistência visual e simplifica o handoff para developers.
