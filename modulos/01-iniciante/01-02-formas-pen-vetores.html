Formas básicas, Pen tool e vetores

Do retângulo mais simples ao ícone mais elaborado, tudo começa com formas e vetores. Dominar a Pen tool é um divisor de águas para qualquer designer.

⏱️ Leitura: ~20 min 🎯 Nível: Iniciante 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Usar todas as ferramentas de forma básica: retângulo, elipse, linha, seta, polígono e estrela;
  • Editar pontos e arredondar cantos com Corner Radius;
  • Usar a Pen tool para criar vetores personalizados;
  • Criar curvas com a técnica de bend (arrastar handles);
  • Usar o Paint Bucket para fechar paths abertas.

Ferramentas de forma básica

O Figma oferece um conjunto de formas geométricas prontas para uso. Você as encontra na barra superior de ferramentas (ou pelos atalhos do teclado). Cada forma pode ser editada em profundidade após criada.

Retângulo (R)

A forma mais usada em UI design. Pressione R, clique e arraste. Segure Shift para criar um quadrado perfeito. No painel direito, além de W, H, X e Y, você controla o Corner Radius — o arredondamento dos cantos. Digite um valor único (para todos os cantos) ou clique no ícone de cantos independentes para arredondar cada canto separadamente.

Corner Radius variável — recurso UI3

No Figma atual (UI3), você pode definir corner radius independente para cada canto. Clique no ícone de mistura ao lado do campo de corner radius. Isso é perfeito para cards com apenas o topo arredondado ou botões com formas assimétricas.

Elipse (O)

Pressione O e arraste para criar uma elipse. Segure Shift para um círculo perfeito. Circles perfeitos são essenciais para avatares, badges e ícones arredondados. Um truque: para criar um avatar circular, crie uma elipse e use-a como máscara (veremos na Lição 5).

Linha (L) e Seta (Shift+L)

A ferramenta Linha (L) cria uma linha reta. A Seta (Shift+L) cria uma linha com ponta de seta em uma ou ambas as extremidades. Você controla a espessura (stroke weight), o tipo de ponta (cap: flat, round, arrow…) e a cor no painel direito.

Polígono e Estrela

Ambas ficam no submenu da ferramenta de elipse (clique e segure o ícone na barra superior). O Polígono cria triângulos, pentágonos, hexágonos — controle o número de lados no campo "Count" do painel. A Estrela tem dois campos: Count (número de pontas) e Ratio (profundidade das reentrâncias, de 0 a 1).

Editando vetores: Vector Edit mode

Toda forma básica é, internamente, um vetor. Para editar os pontos de uma forma, selecione-a e pressione Enter (ou dê duplo-clique). Você entra no Vector Edit mode:

  • Pontos (nodes): os círculos que definem os vértices da forma;
  • Handles (alças): os pontinhos que controlam as curvas de cada segmento;
  • Segmentos: as linhas entre os pontos — você pode clicar em um segmento para adicionar um ponto nele.

No painel direito, quando em Vector Edit mode, você vê o tipo de cada ponto: Straight (vértice reto), Mirrored (handles simétricos, cria curva suave), Disconnected (handles independentes) e Asymmetric (handles com direções independentes mas com mesma distância).

Corner Smoothing — iOS-style

O Figma suporta Corner Smoothing (também chamado de "superellipse" ou squircle), que é exatamente o arredondamento suave usado nos ícones do iOS. No painel direito, com o Corner Radius ativado, você verá o campo de smoothing. Valor 100% = estilo iOS perfeito.

A Pen tool e Vector Networks

A Pen tool (P) é a ferramenta para criar formas vetoriais personalizadas — ícones, ilustrações, formas orgânicas. O Figma usa um sistema de Vector Networks, que é diferente do Illustrator: os segmentos não precisam formar um caminho fechado contínuo. Você pode ter um ponto com 3 ou mais segmentos saindo dele, criando estruturas ramificadas.

Como funciona a Pen tool

  • Clique simples: cria um ponto reto (sharp corner);
  • Clique e arraste: cria um ponto com handles — o arrasto define a curva (técnica Bézier);
  • Fechar o path: clique no primeiro ponto para fechar a forma;
  • Escape: termina o caminho sem fechar;
  • Enter: confirma e sai do modo de edição.

Curvas Bézier — a técnica do bend

Para criar curvas suaves, você usa handles — pares de alças que definem a tangente da curva em cada ponto. A técnica de bend no Figma é mais intuitiva: ao passar o mouse sobre um segmento (não sobre um ponto), o cursor mostra uma curva — clique e arraste o segmento para curvá-lo diretamente, sem precisar manipular handles manualmente. Isso é único no Figma e muito mais rápido para iniciantes.

Paint Bucket — fechar paths abertas

Se você criou um caminho aberto (com vários segmentos que não formam uma forma fechada), o Paint Bucket (B no modo de edição vetorial) preenche o espaço delimitado pelos segmentos mesmo que o caminho não esteja formalmente fechado. É como o bucket fill do Photoshop, mas para vetores.

Passo a passo: desenhar um ícone de casa com a Pen tool

Vamos criar um ícone de "home" simples — um triângulo de telhado sobre um retângulo de parede:

  1. Ative a Pen tool. Pressione P. O cursor vira uma caneta. Você vai criar o telhado (triângulo).
  2. Crie o triângulo do telhado. Clique para criar o ponto esquerdo do telhado. Clique para o ponto do topo (no meio, acima). Clique para o ponto direito. Clique no primeiro ponto para fechar o triângulo. Pressione Enter para confirmar.
  3. Crie o retângulo da parede. Pressione R e desenhe um retângulo abaixo do triângulo para representar a parede da casa.
  4. Unifique as formas (Boolean Union). Selecione os dois elementos (Shift+clique). No menu superior, vá em Object → Union Selection (ou use o dropdown de Boolean na barra de ferramentas). As formas se fundem em um único vetor.
  5. Adicione a porta. Crie um pequeno retângulo com R na parte inferior da parede. Use Subtract Selection para "cortar" a porta da forma unificada.
  6. Ajuste a cor e o tamanho. Selecione o ícone final e dê um fill escuro. Redimensione para 24×24 px segurando Shift+Alt/⌥ ao arrastar para manter proporcional e central.

Boolean Operations — combinar formas

Uma habilidade fundamental para criar ícones é combinar formas usando as Boolean Operations. São 4 modos:

OperaçãoO que fazAtalho (barra superior)
UnionFunde as formas em uma só (área combinada)Dropdown → Union Selection
SubtractRemove a forma do topo da forma de baixoDropdown → Subtract Selection
IntersectMantém apenas onde as formas se sobrepõemDropdown → Intersect Selection
ExcludeMantém onde as formas não se sobrepõemDropdown → Exclude Selection
Boolean não é destrutivo

As Boolean Operations no Figma são não-destrutivas: as formas originais continuam existindo dentro do grupo Boolean e podem ser editadas individualmente entrando no grupo com duplo-clique. Para "achatar" em um único vetor, use Flatten Selection (Ctrl/⌘ + E).

Resumo

  • As formas básicas (R, O, L) são o ponto de partida de qualquer UI.
  • O Corner Radius arredonda cantos; no Figma UI3, cada canto pode ter um valor diferente.
  • A Pen tool (P) cria formas vetoriais livres usando o sistema de Vector Networks.
  • Arrastar um segmento cria curvas (bend) — mais rápido do que manipular handles manualmente.
  • Boolean Operations combinam, subtraem e intersectam formas para criar ícones complexos.
  • Ctrl/⌘ + E achata uma boolean em um único vetor.
✍️ Exercício

Crie um set de 4 ícones

  1. Crie um Frame de 320×120 px para organizar seus ícones.
  2. Ícone 1 — Olho: elipse principal (40×26 px) + elipse menor no centro (14×14 px) com Subtract.
  3. Ícone 2 — Coração: dois círculos sobrepostos + triângulo embaixo com Union, depois rotacione 45°.
  4. Ícone 3 — Estrela: ferramenta Estrela com 5 pontas e Ratio 0.45.
  5. Ícone 4 — Seta de enviar: triângulo com Pen tool, ponta virada para a direita.
Critério de sucesso: os 4 ícones têm 24×24 px cada, fill sólido e foram criados vetorialmente (sem texto ou emoji).
🏆 Desafio

Ilustração de avatar personalizado

Use apenas a Pen tool e as formas básicas para criar um avatar vetorial simples: um rosto redondo com olhos, sorriso e talvez cabelo. Sem usar texto ou imagens — tudo em vetores. Dica: o rosto é uma elipse, os olhos são dois círculos pequenos, a boca é um arco criado com a Pen tool e a técnica de bend. Ao terminar, aplique um gradiente de fill no rosto (próxima lição para os gradientes, mas explore por conta própria!).

QuizTeste seu conhecimento

1. Como você cria uma curva suave com a Pen tool no Figma sem precisar manipular handles manualmente?

  • Pressionar Alt ao clicar em um ponto
  • Usar a ferramenta Pencil em vez da Pen
  • Clicar e arrastar diretamente sobre um segmento (bend)
  • Pressionar C para ativar modo curvo
No Figma, você pode arrastar um segmento (não um ponto) para curvá-lo diretamente. Isso é chamado de "bend" e é exclusivo do Figma — muito mais intuitivo do que manipular handles Bézier tradicionais.

2. Qual Boolean Operation remove a forma do topo da forma de baixo, criando um "buraco"?

  • Union
  • Subtract
  • Intersect
  • Exclude
Subtract Selection remove a área da forma de cima da forma de baixo — é assim que você cria um "buraco" em uma forma, como a pupila dentro do olho ou a porta dentro da casa.

3. Qual atalho "achata" um grupo de Boolean Operations em um único vetor simples?

  • Ctrl/⌘ + G
  • Ctrl/⌘ + F
  • Ctrl/⌘ + B
  • Ctrl/⌘ + E
Ctrl/⌘ + E (Flatten Selection) converte um grupo de Boolean Operations (ou qualquer seleção de vetores) em um único path simples, removendo a estrutura não-destrutiva.
