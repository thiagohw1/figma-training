Frames vs Groups

Antes de desenhar qualquer coisa no Figma, você precisa entender a diferença fundamental entre Frame e Group — a escolha errada aqui vai te travar em lições futuras.

⏱️ Leitura: ~16 min 🎯 Nível: Iniciante 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Explicar com suas palavras a diferença entre Frame e Group;
  • Criar frames usando presets de dispositivos (iPhone, Desktop, etc.);
  • Decidir com segurança quando usar um ou outro;
  • Entender por que o Frame é o bloco fundamental do design no Figma;
  • Trabalhar com frames aninhados (frames dentro de frames).

O que é um Frame?

Um Frame é o container mais importante do Figma. Pense nele como uma tela em branco com dimensões próprias — assim como o canvas de um aplicativo mobile ou o viewport de um site. Todo projeto profissional no Figma começa com Frames.

Tecnicamente, um Frame é um container que:

  • Tem largura e altura definidas de forma independente do conteúdo;
  • Pode ter fill próprio (cor de fundo, gradiente, imagem);
  • Suporta clipping — conteúdo que ultrapassa as bordas pode ser ocultado;
  • Aceita Layout Grids (guias de colunas, linhas e grid uniforme);
  • Pode ser transformado em Auto Layout, Componente e protótipo de tela;
  • Suporta Constraints (regras de ancoragem para os filhos);
  • Aparece no handoff para developers com metadados precisos.
Frame = Artboard no Sketch/XD/Illustrator

Se você veio de outras ferramentas, o Frame do Figma é o equivalente ao Artboard do Sketch ou do Adobe XD. A diferença é que no Figma os Frames são muito mais poderosos: eles podem ser aninhados infinitamente e viram componentes, protótipos e Auto Layouts.

O clip content

Uma propriedade fundamental do Frame é o Clip content (ocultar conteúdo além das bordas). Quando ativado, tudo que sair da área do Frame fica invisível — como uma janela por onde você vê apenas o que está dentro. Isso é essencial para simular scroll, carousels e modais.

O que é um Group?

Um Group é uma maneira simples de juntar elementos para movê-los ou selecioná-los juntos. Diferente do Frame, o Group:

  • Não tem dimensões próprias — o bounding box é calculado automaticamente a partir dos filhos;
  • Não tem fill, border ou efeitos próprios;
  • Não suporta Layout Grids;
  • Não aceita Auto Layout;
  • Redimensiona todos os filhos proporcionalmente ao ser esticado;
  • É apenas uma conveniência de organização — não é um container real.
Group não é Frame — cuidado!

Um erro clássico de iniciante é criar grupos achando que eles são containers. Se você tentar adicionar Auto Layout a um Group, o Figma converte automaticamente o Group em Frame. Isso mostra que o Group é uma estrutura mais fraca — ele não tem capacidade de organizar filhos.

Quando usar cada um?

Use Frame quando:

  • For uma tela do app ou página do site (sempre);
  • For um componente (botão, card, modal, header…);
  • Precisar de fill, border ou efeito no container;
  • For usar Auto Layout;
  • Precisar que o conteúdo que ultrapasse as bordas seja oculto;
  • For criar Layout Grids;
  • For fazer protótipos interativos.

Use Group quando:

  • For agrupar ícones ou elementos decorativos para mover juntos sem complexidade;
  • For um agrupamento temporário durante a edição;
  • Os elementos não precisam de container com estilo próprio;
  • For agrupar ilustrações ou vetores onde o bounding box automático é desejado.
Regra prática do dia a dia

Na dúvida, sempre use Frame. Se mais tarde você precisar de Auto Layout, fill ou constraints, já está no container certo. Um Frame sem fill parece um Group, mas é muito mais capaz.

Frames aninhados

Um dos poderes do Figma é a capacidade de colocar Frames dentro de Frames. Uma tela de app é um Frame grande que contém Frames menores: o Header é um Frame, o Card é um Frame, o Botão dentro do Card é outro Frame. Essa hierarquia é o que permite construir interfaces complexas com precisão.

Frames aninhados formam a estrutura hierárquica de qualquer tela profissional.

Passo a passo: criar uma tela a partir de preset

Vamos criar sua primeira tela de app no Figma:

  1. Ative a ferramenta Frame. Pressione F no teclado. O cursor muda para uma cruz. No painel direito, aparece a lista de presets.
  2. Escolha o preset de iPhone. No painel direito, clique em Phone → iPhone 14 & 15. Um Frame de 390×844 px aparece automaticamente no canvas.
  3. Ou desenhe manualmente. Com F ativo, clique e arraste no canvas para criar um Frame de qualquer tamanho. Segure Shift para forçar proporções quadradas.
  4. Dê um nome ao Frame. No painel de Layers (esquerda), clique duas vezes sobre o nome do Frame e renomeie para "Home – iPhone 14". Nomes descritivos são essenciais.
  5. Adicione um fill de fundo. Com o Frame selecionado, clique no + ao lado de "Fill" no painel direito. Escolha uma cor clara (#F5F6F8, por exemplo). Você acabou de criar sua primeira tela!
  6. Crie um Frame aninhado para o header. Com F, arraste dentro do Frame de tela para criar um Frame filho de 390×60 px no topo. Dê um fill branco e renomeie para "Header".

Resumo

  • Frame é um container com dimensões próprias, fill, clip, grids e suporte a Auto Layout — use para telas, seções e componentes.
  • Group é apenas um agrupamento conveniente sem propriedades de container — use para organizar elementos que devem se mover juntos.
  • Frames podem ser aninhados infinitamente, formando a hierarquia de qualquer interface.
  • Presets de Frame oferecem dimensões prontas para os dispositivos mais comuns.
  • Na dúvida, prefira Frame — ele oferece todos os recursos que o Group oferece, e muito mais.
✍️ Exercício

Monte a estrutura de uma tela simples

Coloque a mão na massa:

  1. Crie um Frame usando o preset iPhone 14 & 15 e renomeie para "Tela – Início".
  2. Dentro dele, crie um Frame filho de 390×60 px no topo, fill branco, renomeado "Header".
  3. Crie um segundo Frame filho de 390×120 px abaixo do header, fill branco com sombra, renomeado "Card – Produto".
  4. Dentro do Card, adicione dois textos (título e subtítulo) usando a ferramenta T.
  5. Agora crie um Group com os dois textos (Ctrl/⌘ + G) e observe que o Group não tem fill próprio.
Critério de sucesso: no painel de Layers, você deve ver "Tela – Início" > "Header" e "Card – Produto" como Frames (ícone de Frame), e dentro do Card um Group com dois textos.
🏆 Desafio

Estrutura de 3 telas conectadas

Crie 3 Frames de iPhone lado a lado representando "Splash Screen", "Login" e "Home". Cada um deve ter fill e pelo menos 3 Frames filhos internos. Organize todos os Frames dentro de outro Frame maior chamado "Fluxo – Onboarding" (sim, um Frame pode conter outros Frames de tela inteira). Isso simula a organização de um projeto real.

QuizTeste seu conhecimento

1. Qual é a principal diferença entre um Frame e um Group no Figma?

  • Frame não aceita filhos; Group aceita
  • Frame tem dimensões próprias e aceita fills, grids e Auto Layout; Group não tem dimensões independentes
  • Group pode ser convertido em componente; Frame não
  • Frame só funciona em telas mobile
O Frame é um container independente com W, H, fills, borders, Layout Grids e suporte a Auto Layout. O Group apenas junta elementos e seu tamanho é calculado automaticamente pelos filhos.

2. Qual atalho cria um Frame no Figma?

  • F
  • Ctrl + G
  • R
  • Shift + A
A tecla F ativa a ferramenta Frame. Ctrl/⌘ + G cria um Group, R cria um retângulo e Shift + A aplica Auto Layout.

3. O que acontece quando você tenta aplicar Auto Layout em um Group?

  • O Figma exibe um erro e impede a ação
  • O Auto Layout é aplicado, mas sem funcionar
  • O Figma converte o Group em Frame automaticamente
  • O Group é deletado
Ao aplicar Auto Layout (Shift + A) em um Group, o Figma converte automaticamente o Group em Frame — porque Auto Layout requer as capacidades de um Frame.
