Plugins e widgets essenciais

O Figma sem plugins é como um smartphone sem aplicativos — funcional, mas muito aquém do potencial. Com os plugins certos, você transforma horas de trabalho em minutos e abre capacidades que a plataforma não entrega nativamente.

⏱️ Leitura: ~20 min 🎯 Nível: Iniciante/Intermediário 🛠️ Pratique no Figma Design

Ao final desta lição você será capaz de

  • Entender a diferença entre plugins e widgets e como instalar cada um;
  • Conhecer os plugins mais importantes por categoria de uso;
  • Usar os plugins essenciais de conteúdo, ícones e acessibilidade;
  • Identificar widgets úteis para o fluxo de trabalho;
  • Entender o processo básico de criação de um plugin próprio.

O que são plugins?

Plugins são extensões desenvolvidas por terceiros (ou pela própria Figma) que rodam dentro do Figma Design e adicionam funcionalidades. Eles são escritos em JavaScript e têm acesso à API do Figma — podendo criar, modificar e organizar elementos no canvas.

Plugins são executados sob demanda: você abre um plugin, ele faz alguma coisa (gera conteúdo, reorganiza camadas, verifica contraste, etc.) e fecha. O resultado fica no canvas como objetos normais do Figma.

Plugins vs. Widgets (novamente)

Lembre-se da distinção que vimos no FigJam: Plugins do Figma Design rodam para um usuário de cada vez e produzem objetos estáticos. Widgets ficam no canvas como objetos persistentes e interativos que todos podem manipular — mas widgets são mais comuns no FigJam. No Figma Design, plugins são a forma mais comum de extensão.

Como instalar e usar plugins

  1. Acesse a Figma Community. Clique no menu principal do Figma (ícone no canto superior esquerdo) → "Plugins" → "Manage plugins" → "Browse plugins in Community". Ou acesse diretamente em figma.com/community.
  2. Encontre um plugin. Busque pelo nome (ex.: "Unsplash") ou navegue pelas categorias. Veja o número de instalações, avaliações e a descrição.
  3. Instale o plugin. Clique em "Install" na página do plugin. O plugin fica salvo no seu perfil e aparece no menu de plugins dentro do Figma.
  4. Execute o plugin. No Figma Design, clique com o botão direito no canvas → "Plugins" → escolha o plugin. Ou use o atalho Ctrl/⌘ + / (Actions) e digite o nome do plugin.
  5. Use a interface do plugin. A maioria dos plugins abre um painel flutuante com sua própria interface. Interaja com ela conforme o plugin pede e confirme para aplicar ao canvas.
Acesso rápido a plugins recentes

O Figma lembra os últimos plugins que você usou. Pressione Ctrl/⌘ + / para abrir o Quick Actions e os últimos plugins aparecem no topo. Isso elimina a necessidade de navegar pelo menu toda vez.

Animação e motion

Stark é obrigatório na toolbox de todo designer

Acessibilidade não é opcional — é lei em muitos países e é a coisa certa a fazer. O Stark elimina as desculpas: em segundos você sabe se um par de cores passa no WCAG AA ou se um daltônico vai conseguir distinguir os estados do seu sistema de feedback. Use em todo projeto.

Widgets úteis no Figma Design

Widgets no Figma Design são menos comuns que no FigJam, mas alguns são muito práticos:

  • Annotations: adiciona anotações visuais de especificação diretamente no canvas, úteis para comunicar detalhes ao desenvolvedor
  • Color Palette Generator: gera paletas de cores harmonizadas a partir de uma cor base
  • Changelog: widget de log de alterações persistente no arquivo — registra o histórico de decisões de design
  • To-do List: lista de tarefas do projeto visível no canvas para toda a equipe

Como criar seu próprio plugin

Criar plugins é mais acessível do que parece. Se você tem conhecimento básico de JavaScript, pode criar seu próprio plugin para automatizar tarefas específicas do seu fluxo de trabalho.

Os ingredientes básicos

  • Conhecimento: JavaScript (nível básico/intermediário)
  • Ferramenta: Figma Desktop + VS Code
  • Documentação: Figma Plugin API Docs

O processo em alto nível

  1. Crie um novo plugin via menu "Plugins" → "Development" → "New Plugin"
  2. Escolha um template (with UI ou sem UI)
  3. Edite o arquivo code.js no VS Code usando a Figma Plugin API
  4. Teste em tempo real com o menu "Development" → "Open console"
  5. Publique na Figma Community quando estiver pronto (ou use só internamente)
Ideia de plugin simples para começar

Um plugin que seleciona todos os textos de uma tela que estão abaixo de 12px (potencialmente ilegíveis) e os destaca em vermelho. Isso usa a API do Figma para iterar sobre nodes, verificar a propriedade fontSize e modificar fills. Funcional em menos de 30 linhas de JavaScript.

Segurança e plugins de terceiros

Plugins têm acesso ao conteúdo do seu arquivo Figma. Antes de instalar um plugin, verifique: o número de instalações (popularity), as avaliações, o desenvolvedor (empresa conhecida ou dev ativo?) e as permissões solicitadas. Evite plugins com poucas instalações, sem avaliações e de desenvolvedores desconhecidos em arquivos com dados sensíveis do cliente.

Exemplo de uso real

Uma designer de UX trabalhando em um Design System para um banco digital usa os seguintes plugins em seu fluxo semanal: (1) Content Reel para preencher telas com dados bancários fictícios realistas (saldos, transações, nomes de beneficiários) em vez de Lorem ipsum; (2) Tokens Studio para sincronizar os design tokens com o repositório Git do time de desenvolvimento — garantindo que o que está no Figma é exatamente o que vai para o código; (3) Stark antes de cada entrega para auditar a acessibilidade dos novos componentes; (4) Design Lint para escanear o arquivo antes do handoff e garantir que não ficou nenhuma cor ou fonte fora da biblioteca. Esses quatro plugins economizam horas de trabalho manual por semana.

Resumo

  • Plugins são extensões JavaScript que rodam no Figma e adicionam funcionalidades via API.
  • Para instalar: Figma Community → Install → execute via menu Plugins ou Quick Actions (Ctrl/⌘ + /).
  • Plugins essenciais: Unsplash (fotos), Content Reel (dados), Iconify (ícones), Stark (acessibilidade), Autoflow (fluxos), Tokens Studio (design tokens), Design Lint (auditoria).
  • Widgets são objetos interativos persistentes no canvas — mais comuns no FigJam, mas existem para o Figma Design também.
  • Criar plugins próprios é viável com JavaScript básico usando a Figma Plugin API.
  • Cuidado com plugins de terceiros desconhecidos — eles têm acesso ao conteúdo dos seus arquivos.
✍️ Exercício

Montar um mockup realista com plugins

Crie uma tela de feed de um app social usando plugins:

  1. Instale Unsplash e Content Reel (se ainda não tiver).
  2. Crie um frame mobile (390×844 px) com a estrutura básica de um feed: 3 posts, cada um com foto, nome de usuário, texto e botões de reação.
  3. Use o Unsplash para inserir fotos reais nos posts (selecione um retângulo placeholder → rode o Unsplash).
  4. Use o Content Reel para preencher os nomes de usuário e textos dos posts com dados realistas.
  5. Instale o Stark e verifique o contraste do texto sobre os elementos de cor do seu design.
Critério de sucesso: a tela tem 3 posts com fotos reais do Unsplash, nomes e textos gerados pelo Content Reel, e o Stark confirma que pelo menos o texto principal passa no WCAG AA (ratio ≥ 4.5:1).
🏆 Desafio

Auditoria completa de Design System com plugins

Pegue um arquivo Figma complexo (qualquer arquivo de exercício anterior ou um arquivo da Figma Community) e conduza uma auditoria completa com plugins: (1) rode o Design Lint e registre quantas inconsistências foram encontradas por tipo (cores fora da biblioteca, fontes desvinculadas, etc.); (2) rode o Stark nas principais telas e documente os pares de cores que falham no WCAG AA; (3) use o Autoflow para conectar as telas do arquivo criando um user flow visual. Entregue um relatório (pode ser um frame no próprio Figma) com os achados e as correções que você fez.

QuizTeste seu conhecimento

1. Qual plugin é considerado indispensável para verificar acessibilidade de cores no Figma?

  • Autoflow
  • Content Reel
  • Stark
  • Figmotion
O Stark é o plugin de acessibilidade mais completo para Figma: verifica contraste WCAG, simula deficiências visuais e gera relatórios — indispensável para qualquer designer que leve acessibilidade a sério.

2. O que o plugin Tokens Studio (anteriormente Figma Tokens) faz?

  • Gera tokens de autenticação para o Figma API
  • Gerencia design tokens em JSON, sincroniza com Git e exporta para código — integrando Figma ao pipeline de desenvolvimento
  • Cria componentes tokenizados automaticamente a partir de frames selecionados
  • Substitui as Variables nativas do Figma por uma versão mais avançada
O Tokens Studio é o padrão da indústria para gerenciar design tokens no Figma, com suporte a sincronização Git e exportação para Style Dictionary — permitindo que design e código compartilhem os mesmos tokens.

3. Por que é importante verificar a reputação de um plugin antes de instalá-lo?

  • Plugins populares carregam mais rápido
  • Plugins de desenvolvedores desconhecidos cobram mensalidade automaticamente
  • Plugins novos travam o Figma com mais frequência
  • Plugins têm acesso ao conteúdo dos arquivos Figma — um plugin malicioso poderia expor dados sensíveis do cliente
A Figma Plugin API dá aos plugins acesso de leitura e escrita ao conteúdo dos arquivos. Um plugin malicioso poderia enviar dados sensíveis (wireframes de produtos não lançados, dados de clientes em mockups) para servidores externos. Sempre verifique a reputação antes de instalar.
