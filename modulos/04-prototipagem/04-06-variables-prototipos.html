Variables em protótipos: lógica e expressões

Variables transformam protótipos estáticos em experiências com lógica real: contadores que somam, formulários que validam, temas que alternam e fluxos que seguem caminhos diferentes conforme o estado da aplicação — tudo sem código, dentro do Figma.

⏱️ Leitura: ~25 min 🎯 Nível: Avançado 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Criar e organizar Variables de diferentes tipos para uso em protótipos;
  • Usar a action Set variable para alterar valores durante a interação;
  • Criar lógica condicional (if/else) com a action Conditional;
  • Escrever expressões simples para cálculos e comparações;
  • Implementar exemplos funcionais: contador de carrinho, toggle de tema e login básico.

Variables no contexto de protótipos

No Módulo 3, você aprendeu Variables como ferramenta de Design Tokens (cores, espaçamentos). Em protótipos, as Variables ganham um papel completamente diferente: elas armazenam estado — informações que mudam conforme o usuário interage.

Pense em uma variável de protótipo como uma memória temporária: ela guarda "quantos itens estão no carrinho", "o usuário está logado?" ou "o tema atual é claro ou escuro". Quando o usuário interage, você altera o valor da variável; o protótipo lê esse valor e exibe o conteúdo correto.

Tipos de Variable para protótipos

Number: valores numéricos (contador, quantidade, progresso). String: texto (nome do usuário, mensagem de erro). Boolean: verdadeiro/falso (logado, tema escuro, menu aberto). Color: uma cor (para alternar temas dinamicamente nos Design Tokens).

Onde criar Variables para protótipos

  1. Abra o painel de Variables: Local variables via menu Edit → Local variables, ou o ícone de variável no painel direito.
  2. Crie uma coleção chamada "Prototype State" (ou qualquer nome descritivo).
  3. Dentro da coleção, adicione as variáveis necessárias. Para expô-las no protótipo, marque a opção "Can be hidden in publishing" como false e certifique-se de que o escopo inclui All scopes ou Prototype.
Valores iniciais importam

O valor inicial de uma variável é o estado de "reset" do protótipo. Ao reiniciar o Present mode, todas as variáveis voltam ao valor inicial. Defina valores iniciais que representem o estado vazio ou padrão da experiência: contador = 0, logado = false, tema = "light".

A action Set variable

A action Set variable altera o valor de uma variável quando um trigger é ativado. Na configuração da Connection:

  • Variable: qual variável alterar.
  • Value: novo valor fixo (ex.: 1, "dark", true) ou uma expressão (ex.: carrinho + 1).

Você pode encadear múltiplas actions em uma única interação: On click → Navigate to (frame) + Set variable (carrinho = carrinho + 1). Ambas acontecem ao mesmo tempo.

Expressões

Expressões permitem calcular o novo valor de uma variável com base no valor atual ou em outras variáveis. A sintaxe é simples, similar a uma calculadora:

Conditional — lógica if/else

A action Conditional avalia uma condição e executa ações diferentes dependendo do resultado:

  • If (condição): executa a action do ramo verdadeiro.
  • Else: executa a action do ramo falso (opcional).

Exemplos de condições:

  • carrinho > 0 — há itens no carrinho?
  • logado == true — o usuário está logado?
  • senha == "1234" — a senha está correta? (para login simulado)
  • tema == "dark" — o tema atual é escuro?
Limitações das condições

O Conditional do Figma suporta comparações simples (==, !=, >, <, >=, <=). Não suporta && (AND) ou || (OR) diretamente na mesma condição — para lógica combinada, use Conditionals aninhados ou variáveis auxiliares.

Vinculando Variables a conteúdo de texto

Para que o protótipo exiba o valor atual de uma variável em um texto:

  1. Selecione a camada de texto no canvas.
  2. No painel de Design, ao lado do conteúdo do texto, clique no ícone de variável.
  3. Selecione a variável desejada. O texto agora exibe o valor atual da variável.

Ao alterar a variável via Set variable durante a interação, o texto se atualiza automaticamente no Present mode — sem precisar navegar para outro frame.

Passo a passo: contador de carrinho funcional

Vamos criar um contador de itens que incrementa e decrementa com cliques reais:

  1. Crie a variável. Abra Local variables. Crie uma coleção "Carrinho". Adicione uma variável quantidade do tipo Number, valor inicial 0.
  2. Monte a UI do contador. Crie um frame com três elementos: botão "–" (minus), um texto de exibição (ex.: "0") e botão "+" (plus). O texto de exibição deve ser uma camada de texto chamada "Quantidade display".
  3. Vincule o texto à variável. Selecione a camada "Quantidade display". No painel Design, clique no ícone de variável ao lado do conteúdo do texto e selecione quantidade.
  4. Configure o botão "+". Aba Prototype → selecione o botão "+". Adicione interação: Trigger = On click. Action = Set variable. Variable = quantidade. Value = quantidade + 1 (expressão).
  5. Configure o botão "–". Selecione o botão "–". Trigger = On click. Action = Conditional. Condição: quantidade > 0. Se verdadeiro: Set variable → quantidade = quantidade - 1. (O else pode ficar vazio — não faz nada se já for 0.)
  6. Teste no Present mode. Clique em "+" várias vezes — o número sobe. Clique em "–" — desce, mas para em 0. Reinicie o protótipo — volta a 0. O contador funciona!

Exemplo 2: toggle de tema claro/escuro

Variável: tema (Boolean, valor inicial: false = claro).

  • No botão de toggle de tema, On click → Set variable: tema = !tema (inverte o booleano).
  • Vincule as cores dos frames (via Variables de cor) ao modo "light" ou "dark" da coleção de design tokens.
  • Na prática avançada: crie duas coleções de color variables (light e dark) e use o valor de tema para alternar entre elas via Set variable com a variável de modo do collection.

Exemplo 3: login simples com Conditional

Variáveis: senhaCorreta (Boolean, false); tentativas (Number, 0).

  • Campo de senha: o usuário digita (simulado com variants de input).
  • Botão "Entrar": On click → Conditional: senhaCorreta == true. If true → Navigate to "Home". Else → Set variable tentativas = tentativas + 1 + Conditional: tentativas >= 3 → Navigate to "Conta bloqueada".
  • Para o protótipo funcionar, você precisará de um botão "Senha correta" em modo de apresentação que defina senhaCorreta = true — um "modo de teste" oculto fora da tela.
Variables + Interactive Components = protótipos ricos

A combinação mais poderosa: Interactive Components gerenciam estados visuais (hover, pressed, checked), enquanto Variables gerenciam estados de dados (contadores, autenticação, preferências). Juntos, eles cobrem praticamente toda a lógica necessária para testes de usabilidade realistas — sem código.

Exemplo de uso real

Em um protótipo de app de e-commerce para teste de usabilidade:

  • Variável carrinhoCount (Number): cada botão "Adicionar ao carrinho" incrementa a variável. O ícone do carrinho no header mostra o valor via text binding. O badge fica visível só quando o valor é maior que 0 (Conditional).
  • Variável favorito (Boolean) por produto: o botão de coração alterna com !favorito. O ícone troca entre coração vazio e preenchido (Interactive Component + Set variable).
  • Variável enderecoSalvo (Boolean): no checkout, se o endereço já está salvo (true), pula direto para pagamento; se não (false), mostra o formulário de endereço (Conditional no botão "Continuar").

Resumo

  • Variables armazenam estado no protótipo: números, textos, booleanos e cores.
  • A action Set variable altera o valor — com um valor fixo ou uma expressão.
  • Expressões permitem cálculos simples: variavel + 1, !variavel, concatenação.
  • A action Conditional cria ramificações if/else baseadas em condições.
  • Vincule variáveis a camadas de texto para exibir valores dinâmicos no Present mode.
  • Variables + Interactive Components = protótipos com lógica real sem código.

Contador funcional de carrinho

  1. Crie a variável quantidade (Number, valor inicial 0).
  2. Monte a UI com botões "–", display de número e "+".
  3. Vincule o display à variável.
  4. Configure o botão "+": On click → Set variable → quantidade + 1.
  5. Configure o botão "–": On click → Conditional (quantidade > 0) → Set variable → quantidade - 1.
  6. Adicione um badge "Carrinho (N)" em um header usando a mesma variável.
Critério de sucesso: no Present mode, o contador incrementa e decrementa. Nunca vai abaixo de 0. O badge no header atualiza em tempo real com o mesmo valor.
🏆 Desafio

Formulário com validação

Crie um formulário de login com dois campos (email e senha — simulados com variants de componente de input). Crie variáveis booleanas emailPreenchido e senhaPreenchida. Ao "preencher" cada campo (clicar em uma variante Filled do Input), defina a variável correspondente como true. O botão "Entrar" deve usar Conditional encadeado: se ambas as variáveis forem true, navega para o Dashboard; caso contrário, exibe uma mensagem de erro (Set variable em uma variável mostrarErro que controla a visibilidade de um texto de alerta).

QuizTeste seu conhecimento

1. Qual expressão você usaria no campo "Value" de um Set variable para inverter um booleano chamado "menuAberto"?

  • menuAberto = false
  • menuAberto == true
  • menuAberto - 1
  • !menuAberto
O operador ! (NOT) inverte um booleano: se for true, torna-se false, e vice-versa. É a expressão correta para alternar um toggle, menu ou tema com uma única action.

2. Para exibir o valor atual de uma variável Number em uma camada de texto no Present mode, o que você deve fazer?

  • Criar uma Connection com a action "Set variable" apontando para a camada de texto
  • Selecionar a camada de texto e vincular a variável via o ícone de variável no painel de Design, ao lado do conteúdo do texto
  • Renomear a camada de texto com o mesmo nome da variável
  • Usar a action "Scroll to" com a variável como parâmetro
O text binding é feito selecionando a camada de texto e clicando no ícone de variável no painel de Design (ao lado do valor do texto). Após vincular, o texto exibe o valor atual da variável dinamicamente no Present mode.

3. Qual é o comportamento das variáveis quando o usuário reinicia o protótipo (fecha e reabre o Present mode)?

  • Todas as variáveis voltam aos seus valores iniciais definidos na coleção
  • As variáveis mantêm os últimos valores (estado persistido)
  • As variáveis são deletadas e precisam ser redefinidas
  • Apenas variáveis Boolean fazem reset; Number e String mantêm os valores
Ao reiniciar o Present mode, todas as variáveis voltam ao valor inicial definido na coleção de variáveis. Isso é importante para definir o estado correto do protótipo no início de cada sessão de teste.
