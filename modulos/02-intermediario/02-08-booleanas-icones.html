Operações booleanas e ícones

Operações booleanas são a tesoura e a cola do design vetorial: combinando formas simples você cria ícones sofisticados sem precisar de ferramentas externas. Aprenda a fazer, organizar e distribuir ícones como um designer de sistema.

⏱️ Leitura: ~22 min 🎯 Nível: Intermediário 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Usar as quatro operações booleanas: Union, Subtract, Intersect e Exclude;
  • Usar Flatten para simplificar vetores compostos;
  • Criar ícones consistentes em uma grade de 24×24 px com espessura e alinhamento óptico corretos;
  • Transformar ícones em componentes e usar Instance Swap para trocar ícones em outros componentes.

As quatro operações booleanas

Operações booleanas combinam duas ou mais formas vetoriais usando lógica de conjuntos. O resultado é uma nova forma derivada da interseção, diferença ou soma das formas originais.

Para usar: selecione duas ou mais shapes, vá ao menu Object → Boolean operations, ou use o menu suspenso no ícone de operações booleanas na barra superior.

As quatro operações booleanas aplicadas a dois círculos sobrepostos. Union une; Subtract remove B de A; Intersect mantém apenas a sobreposição; Exclude remove a sobreposição.

Union — Soma

Union combina todas as formas em uma única shape que é a soma de todas. Formas sobrepostas se fundem. A cor do resultado é a da forma mais ao fundo. Use para criar formas compostas onde partes se unem — como o body de uma notificação + a "cauda" do balão de chat.

Atalho: Ctrl + Alt + O (Windows) / ⌘ + ⌥ + O (Mac).

Subtract — Corte

Subtract remove a área da forma superior da forma inferior. O resultado é a forma de baixo com um "buraco" no formato da forma de cima. Use para criar buracos e recortes — o fundo branco de um ícone de câmera, o olho de uma agulha, o interior de um aro.

Atalho: Ctrl + Alt + S (Windows) / ⌘ + ⌥ + S (Mac).

Intersect — Interseção

Intersect mantém apenas a área onde as formas se sobrepõem. Tudo que está fora da sobreposição desaparece. Use para criar shapes complexos que surgem da sobreposição — o ícone de "lente" que corta um círculo em curva.

Atalho: Ctrl + Alt + I (Windows) / ⌘ + ⌥ + I (Mac).

Exclude — Exclusão

Exclude mantém tudo exceto a área de sobreposição. É o oposto do Intersect. Use para criar formas em anel (donut) ou shapes com "janelas" de formas irregulares.

Atalho: Ctrl + Alt + X (Windows) / ⌘ + ⌥ + X (Mac).

Operações booleanas são não-destrutivas

Ao aplicar uma operação booleana, as formas originais ainda existem como camadas filhas do grupo booleano — você pode editá-las a qualquer momento. Para tornar o resultado definitivo e simplificar o arquivo, use Flatten (veja abaixo).

Flatten — simplificar

Flatten (Ctrl + E / ⌘ + E) converte um grupo booleano (ou qualquer combinação de shapes) em um único caminho vetorial. O resultado é um vetor simples, sem hierarquia de camadas — mais leve e fácil de exportar.

Use Flatten quando:

  • Terminou de editar o ícone e quer uma forma limpa para exportar como SVG.
  • Precisa de um único path para fazer mais operações booleanas.
  • Quer reduzir a complexidade de camadas em um componente de ícone.
Flatten é destrutivo

Ao dar Flatten, as formas individuais se fundem permanentemente. Você perde a capacidade de editar cada shape separadamente. Use com frequência o Ctrl/⌘ + Z (undo) se quiser voltar atrás, ou mantenha uma cópia do grupo booleano em uma página de rascunho.

Vector networks: edição de nós

O Figma usa um sistema de Vector Networks que vai além dos paths tradicionais do SVG: um path não precisa ser uma curva fechada — você pode ter caminhos abertos que se ramificam como uma árvore.

Para entrar no modo de edição vetorial, pressione Enter sobre uma shape ou clique no ícone de "Edit vector" (lápis) na barra superior. Você verá os nós (pontos âncora) e as alças de Bézier. Operações possíveis:

  • Adicionar nó: clique em qualquer ponto do caminho.
  • Deletar nó: selecione e pressione Delete.
  • Converter nó: Ctrl + clique no nó (Win) / ⌘ + clique (Mac) — alterna entre curvo e anguloso.
  • Mover nó: selecione e arraste, ou use as setas do teclado.

Criando ícones consistentes

Ícones de qualidade profissional seguem regras rigorosas de consistência. Aqui estão os padrões:

A grade do ícone (24×24 px)

O tamanho mais comum para ícones de interface é 24×24 px (também chamado de "base unit"). Algumas libraries usam 16px (pequenos) e 32px (grandes). A grade de ícone define:

  • Área de segurança: a área interna onde o ícone deve estar. Em 24×24, geralmente é 20×20 (2px de margem em cada lado).
  • Key shapes: formas-guia (quadrado 18×18, círculo 20px de diâmetro) que ajudam a equilibrar o peso visual entre ícones de formas diferentes.

Espessura de stroke

Para ícones de linha (outline), use espessura consistente em toda a biblioteca. O padrão mais comum é 1.5px para ícones de 24×24 (leve e elegante) ou 2px (mais bold e acessível). Nunca misture 1px e 2px na mesma biblioteca.

Configure o stroke com Align: Center (stroke centralizado na borda do path, não dentro nem fora). Isso garante que a bounding box do ícone seja exatamente 24×24.

Alinhamento óptico

Formas geométricas diferentes têm pesos visuais diferentes. Um ícone circular parece menor que um quadrado do mesmo tamanho. Para compensar, designers de ícones usam o alinhamento óptico: círculos são um ou dois pixels maiores que a key shape, e triângulos são maiores ainda. Use as key shapes como guia, não como limite absoluto.

Dica de ícone profissional: corner radius consistente

Defina um corner radius padrão para todos os ícones da biblioteca — ex.: 2px para round, 0px para sharp. Isso cria uma identidade de estilo coerente. No Figma, você pode aplicar corner radius em nós individuais do vetor: selecione um nó no modo de edição vetorial e ajuste o "Corner radius" no painel direito.

Passo a passo: criando um ícone de sino (notificação) do zero

  1. Crie o frame do ícone. Pressione F e crie um frame 24×24 px. Ative o layout grid (Grade de 8px) para facilitar o alinhamento. Defina o fill como "none" (o ícone é transparente por padrão).
  2. Desenhe o corpo do sino. Crie uma elipse (O) de 16×18 px centralizada. Aplique Subtract com um retângulo de 16×8 px na base para criar o formato de sino. Alternativa: crie um retângulo com as alças arredondadas no topo usando o editor vetorial.
  3. Adicione o cabo. Crie um retângulo pequeno de 4×2 px no topo centralizado. Aplique Union com o corpo do sino.
  4. Adicione o badalo (base). Crie uma elipse de 6×4 px na parte inferior. Aplique Union ao conjunto.
  5. Aplique o stroke. Em vez de fill, use apenas Stroke: cor preto (ou a cor do ícone), espessura 1.5 px, Align Center. Remova qualquer fill.
  6. Flatten e limpar. Selecione todo o ícone e pressione Ctrl/⌘ + E (Flatten) para ter um único path limpo.
  7. Transforme em componente. Selecione o ícone (dentro do frame 24×24), pressione Ctrl/⌘ + Alt/⌥ + K. Nomeie: Icon/Bell.

Ícones como componentes: Instance Swap na prática

Com cada ícone transformado em componente (Icon/Bell, Icon/Home, Icon/Search...), você pode usar Instance Swap (visto na lição anterior) para trocar ícones em outros componentes sem precisar criar variants para cada possibilidade.

Exemplo: um componente Nav/Item tem uma property Instance Swap chamada "Icon". O designer arrasta o Nav/Item para a tela, seleciona a instance e troca o ícone no painel direito — sem entrar na hierarquia de camadas, sem fazer detach.

Resumo

  • Union une formas; Subtract corta; Intersect mantém a sobreposição; Exclude remove a sobreposição.
  • Operações booleanas são não-destrutivas — as shapes originais ficam editáveis como camadas filhas.
  • Flatten simplifica para um único path — use ao final da criação.
  • Ícones de 24×24 px com stroke de 1.5-2 px e Align Center garantem consistência.
  • Converta cada ícone em componente e use Instance Swap para trocar ícones em outros componentes.
✍️ Exercício

Crie 4 ícones básicos do zero

  1. Crie 4 frames de 24×24 px.
  2. No primeiro, crie um ícone de lupa (Search): círculo de 14px com Subtract de um retângulo para criar o cabo.
  3. No segundo, crie um ícone de coração: dois círculos + um triângulo, unidos com Union.
  4. No terceiro, crie um ícone de cadeado: retângulo + Subtract de arco superior + círculo no meio.
  5. No quarto, crie qualquer ícone à sua escolha usando pelo menos uma operação booleana.
  6. Transforme cada ícone em componente: Icon/Search, Icon/Heart, Icon/Lock, Icon/Custom.
Critério de sucesso: os 4 ícones têm tamanho 24×24 px, stroke de 1.5px (Align Center), foram criados com operações booleanas visíveis na hierarquia de camadas, e estão como componentes no painel Assets.

QuizTeste seu conhecimento

1. Você quer criar um ícone de donut (anel) usando operações booleanas. Dois círculos sobrepostos no centro. Qual operação usar?

  • Union
  • Exclude
  • Intersect
  • Subtract
Exclude mantém tudo exceto a área de sobreposição. Com dois círculos concêntricos (um grande e um pequeno no centro), Exclude resulta no anel (donut). Subtract também funciona se o círculo menor for a "forma de cima" na hierarquia.

2. Qual é a diferença principal entre uma operação booleana e o Flatten?

  • Flatten aceita mais de duas shapes; booleanas só duas
  • Booleanas só funcionam com circles; Flatten com qualquer shape
  • Booleanas são não-destrutivas (editáveis); Flatten é destrutivo (único path)
  • Flatten adiciona efeitos; booleanas não
Operações booleanas mantêm as formas originais como filhos do grupo booleano — não-destrutivo. Flatten converte tudo em um único path definitivo — destrutivo. Use booleanas para editar; Flatten para finalizar.

3. Qual espessura de stroke e alinhamento é recomendado para ícones de 24×24 px em uma biblioteca profissional?

  • 1.5px ou 2px, Align Center
  • 1px, Align Inside
  • 3px, Align Outside
  • Qualquer espessura, desde que seja consistente
1.5px ou 2px com Align Center é o padrão profissional para ícones de 24px. Align Center garante que a bounding box seja exatamente 24×24, sem overflow. Align Inside ou Outside deslocam o stroke para dentro/fora do path, afetando o tamanho final.
