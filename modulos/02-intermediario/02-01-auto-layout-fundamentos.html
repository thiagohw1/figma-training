Auto Layout — fundamentos

Se existe uma ferramenta que separa o iniciante do profissional no Figma, é o Auto Layout. Ele faz seus layouts se ajustarem sozinhos ao conteúdo — exatamente como uma interface real se comporta.

⏱️ Leitura: ~18 min 🎯 Nível: Intermediário 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Explicar o que é Auto Layout e por que ele é tão importante;
  • Transformar qualquer seleção em um frame de Auto Layout;
  • Controlar os três pilares: direção, espaçamento (gap) e padding;
  • Construir um botão e um card que se ajustam automaticamente ao conteúdo.

O que é Auto Layout?

Auto Layout é um recurso que transforma um frame comum em um container inteligente: em vez de você posicionar cada elemento manualmente com coordenadas X/Y, o frame organiza seus filhos automaticamente em uma linha ou coluna, com espaçamento e margens consistentes.

Se você já ouviu falar de Flexbox no CSS, o Auto Layout é praticamente a versão visual disso. E não é coincidência: quando o desenvolvedor for transformar seu design em código, um Auto Layout vira um container flex quase 1:1.

A grande mudança de mentalidade

Sem Auto Layout, você desenha posições. Com Auto Layout, você descreve regras (“itens empilhados na vertical, com 16 px entre eles, e 24 px de margem”). O Figma cuida do resto — inclusive quando o conteúdo muda de tamanho.

Por que isso muda tudo?

  • Conteúdo dinâmico: um botão cresce sozinho quando o texto fica maior — sem você arrastar nada.
  • Consistência: espaçamentos ficam padronizados em vez de “quase alinhados”.
  • Velocidade: adicionar, remover ou reordenar itens reorganiza o layout instantaneamente.
  • Componentes de verdade: a maioria dos componentes profissionais (botões, inputs, cards, listas) só funciona bem com Auto Layout.

A anatomia de um Auto Layout

Todo frame de Auto Layout tem três propriedades essenciais. Veja como elas se encaixam:

Os três pilares: a direção (linha ou coluna), o gap (espaço entre os filhos) e o padding (margem interna do frame).

Passo a passo: seu primeiro Auto Layout

Vamos criar um botão simples com um ícone e um texto. Abra um arquivo no Figma e acompanhe:

  1. Crie os elementos. Adicione um texto (tecla T) escrevendo “Continuar” e, ao lado, um pequeno ícone ou um quadrado (R) de 20×20 px para simular o ícone.
  2. Selecione os dois. Clique e arraste sobre os elementos, ou segure Shift e clique em cada um, para selecionar ambos.
  3. Aplique o Auto Layout. Pressione Shift + A. O Figma envolve a seleção em um frame e os organiza lado a lado. Pronto — esse já é um Auto Layout!
  4. Encontre o painel. Com o frame selecionado, olhe o painel direito: surgiu uma seção Auto layout com botões de direção, campos de gap e padding.
  5. Ajuste a aparência. Dê um fill de cor ao frame, aumente o padding e arredonde os cantos (corner radius). Você acabou de criar um botão que cresce sozinho se o texto mudar.
Atalho que você vai usar o dia inteiro

Shift + A adiciona Auto Layout. Para remover, use Shift + Alt + A (Windows) / Shift + ⌥ + A (Mac).

Os três pilares na prática

1. Direção (horizontal, vertical ou wrap)

Define se os filhos ficam lado a lado (linha) ou empilhados (coluna). No painel, os ícones de direção alternam entre horizontal (→) e vertical (↓). Existe também o wrap, que “quebra” os itens para a próxima linha quando não cabem — útil para grades de tags e galerias (veremos a fundo na próxima lição).

2. Espaçamento entre itens (gap)

É a distância entre cada filho. Digite um valor fixo (ex.: 16) no campo de gap. Se você definir como Auto, o Figma distribui o espaço disponível entre os itens — é assim que se faz, por exemplo, um cabeçalho com o logo na esquerda e o menu na direita (“space between”).

3. Padding (margem interna)

É o espaço entre a borda do frame e seus filhos. Você pode definir um valor único para todos os lados, valores separados para horizontal/vertical, ou um valor independente para cada lado clicando no ícone de padding individual.

PropriedadeO que controlaExemplo de valor
DireçãoLinha, coluna ou wrapVertical (↓)
GapEspaço entre os filhos16 ou Auto

AlinhamentoPosição dos filhos dentro do frameCentro, topo, etc. (próxima lição)

Exemplo de uso real: um card de produto

Imagine um card com imagem, título, preço e botão. Com Auto Layout vertical, gap de 12 e padding de 16, o card inteiro se reorganiza sozinho se o título virar duas linhas ou se você adicionar uma tag de “Promoção”. Veja a ideia:

Erros comuns de iniciante

1. Usar Group (Ctrl/⌘ + G) achando que é Auto Layout — Group só agrupa, não organiza. 2. Esquecer que o frame com Auto Layout ignora posições manuais: você não “arrasta” mais os filhos livremente, você muda a ordem. 3. Misturar espaçamentos no olho em vez de usar o gap.

Dica de profissional

Pense em Auto Layout como caixas dentro de caixas. Um card é um Auto Layout vertical que contém uma linha (Auto Layout horizontal) com preço e botão. Aninhar Auto Layouts é o segredo para montar telas inteiras que respondem ao conteúdo.

Resumo

  • Auto Layout transforma um frame em um container que organiza os filhos automaticamente.
  • Os três pilares são direção, gap e padding.
  • Use Shift + A para aplicar; configure tudo no painel direito.
  • Aninhar Auto Layouts (caixas dentro de caixas) é a base de telas inteiras.
✍️ Exercício

Crie um botão e um card

Coloque a mão na massa:

  1. Crie um botão com ícone + texto usando Auto Layout horizontal (padding 12×20, gap 8, cantos arredondados).
  2. Troque o texto por algo bem maior e confirme que o botão cresce sozinho.
  3. Crie um card vertical com imagem, título e botão, reaproveitando o botão que você fez.
Critério de sucesso: ao editar qualquer texto, nada quebra nem desalinha — o layout se reajusta sozinho.
🏆 Desafio

Cabeçalho “space between”

Monte o cabeçalho de um app: um logo à esquerda e dois ícones à direita, dentro de um único Auto Layout horizontal que ocupa toda a largura. Use o gap em modo Auto para empurrar os grupos para as extremidades. Dica: você vai precisar que o frame tenha largura fixa (veremos resizing na próxima lição).

QuizTeste seu conhecimento

1. Qual atalho aplica Auto Layout à seleção?

  • Ctrl/⌘ + G
  • Ctrl/⌘ + Alt + G
  • Shift + A
  • Shift + Ctrl + L
Shift + A aplica Auto Layout. Ctrl/⌘ + G cria um Group (que não organiza nada automaticamente).

2. O que o valor “Auto” no campo de gap faz?

  • Define o gap como 0
  • Distribui o espaço disponível entre os itens (space between)
  • Copia o valor do padding
  • Ativa o modo wrap
Gap em Auto empurra os itens para as extremidades, distribuindo o espaço livre — perfeito para cabeçalhos com logo de um lado e menu do outro.

3. Qual conceito do CSS o Auto Layout mais se parece?

  • Grid de impressão
  • position: absolute
  • float
  • Flexbox
Auto Layout é, na prática, a versão visual do Flexbox — por isso vira código tão facilmente no handoff.
