Estilos: color, text, effect e grid

Styles são a memória de design do Figma: uma coleção nomeada de propriedades (cor, tipografia, sombra, grid) que você aplica com um clique e atualiza em um único lugar. Eles são o alicerce de qualquer design system consistente.

⏱️ Leitura: ~20 min 🎯 Nível: Intermediário 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Criar, aplicar e editar os quatro tipos de Styles: Color/Paint, Text, Effect e Layout Grid;
  • Organizar styles em grupos e subgrupos com a barra "/";
  • Atualizar um style e ver a propagação em todo o arquivo;
  • Entender a diferença entre Styles e Variables (e quando usar cada um).

O que são Styles?

Um Style é um conjunto nomeado de propriedades que pode ser vinculado a elementos do canvas. Quando você aplica um Style a um elemento e depois edita o Style, todos os elementos vinculados a ele se atualizam automaticamente.

Pense em Styles como a versão visual de uma variável de design: em vez de usar o hexadecimal #6c4cf1 em 200 elementos, você usa o style "Brand/Primary" — e, quando a cor da marca muda, você edita o style uma vez e todo o arquivo reflete.

Styles são para o designer; Variables são para o handoff e responsividade

Styles são excelentes para gerenciar propriedades visuais no design. Variables (veja o Módulo 3) vão além: suportam múltiplos modos (tema claro/escuro), se integram a prototipagem com lógica e são lidas diretamente pelos desenvolvedores em ferramentas modernas. Para 90% dos projetos, Styles são suficientes e mais simples. Quando precisar de temas ou lógica condicional, use Variables.

Tipo 1: Color / Paint Styles

Um Color Style salva uma cor (sólida, gradiente ou imagem) como um valor nomeado reutilizável. Você pode aplicar color styles em:

  • Fill (cor de fundo de frames, shapes e textos)
  • Stroke (cor da borda)
  • Elementos de efeito (sombras e blurs — veremos em Effect Styles)

Criando um Color Style

  1. Selecione um elemento com a cor que quer salvar (ou crie um retângulo com a cor).
  2. No painel Fill, clique nos quatro pontinhos (⠿) ao lado da cor. Isso abre o gerenciador de styles.
  3. Clique em "+" para criar um novo style. Digite o nome usando a convenção com "/" para grupos: Brand/Primary, Neutral/100, Semantic/Error.
  4. Clique em "Create style". O style aparece no painel e fica disponível para o arquivo inteiro.

Aplicando um Color Style

Selecione o elemento, clique no seletor de Fill e, em vez de digitar uma cor, clique nos quatro pontinhos para abrir o seletor de styles. Selecione o style desejado — o elemento fica vinculado.

Como editar um Color Style

No painel Assets (aba Styles) ou no painel Local styles (clique em qualquer fill vinculado a um style), dê duplo clique no style para abrir o editor. Ao alterar a cor, todos os elementos vinculados a esse style se atualizam imediatamente em todo o arquivo.

Tipo 2: Text Styles

Text Styles salvam um conjunto de propriedades tipográficas: fonte, peso, tamanho, line-height, letter-spacing, text-transform. São aplicados às camadas de texto.

Criando um Text Style

  1. Selecione uma camada de texto e configure todas as propriedades tipográficas no painel direito.
  2. No painel Text, clique em quatro pontinhos ao lado do nome da fonte.
  3. Clique em "+", nomeie o style (ex.: Heading/H1) e crie.

Tipo 3: Effect Styles

Effect Styles salvam sombras (Drop shadow, Inner shadow) e desfocagens (Layer blur, Background blur). Use para definir a elevação dos seus componentes de forma consistente:

  • Shadow/sm — sombra leve para cards e chips (1-2px)
  • Shadow/md — sombra média para dropdowns e menus (4-8px)
  • Shadow/lg — sombra forte para modals e popovers (12-24px)
  • Blur/frosted — background blur para glassmorphism

Criando um Effect Style

  1. Selecione um frame. No painel Effects, clique no "+" para adicionar um drop shadow. Configure os valores (offset X/Y, blur, spread, cor e opacidade).
  2. Clique nos quatro pontinhos ao lado do effect e depois em "+" para criar o style.
  3. Nomeie: Shadow/md, Shadow/card, Blur/frosted.

Tipo 4: Layout Grid Styles

Layout Grid Styles salvam configurações de grid (colunas, linhas, ou grid uniforme) para reutilização. Isso garante consistência nos grids de layout entre telas e designers. Exemplos:

  • Grid/Mobile — 4 colunas, margin 16, gutter 16
  • Grid/Tablet — 8 colunas, margin 24, gutter 20
  • Grid/Desktop — 12 colunas, margin 80, gutter 24

Organizando com grupos e subgrupos (/)

A barra / no nome do style cria uma estrutura hierárquica no painel. Por exemplo:

  • Brand/Primary, Brand/Secondary, Brand/Tertiary → grupo "Brand"
  • Neutral/50, Neutral/100, ..., Neutral/900 → escala de cinzas
  • Semantic/Success, Semantic/Warning, Semantic/Error → cores semânticas

Você pode criar quantos níveis quiser: Text/Body/Large, Text/Body/Small, etc.

Cuidado com nomes genéricos demais

Evite nomear styles como Roxo escuro ou Texto grande — são descritivos do valor, não do uso. Prefira nomes semânticos: Brand/Primary, Heading/H1. Assim, ao mudar a cor de "primary" de roxo para azul, você não precisa renomear o style — ele continua chamando Brand/Primary e o valor muda internamente.

Teaser: Variables no Módulo 3

Variables cobrem o que Styles não conseguem: um mesmo token de cor que muda automaticamente de #6c4cf1 (claro) para #9b81ff (escuro) ao trocar de modo. Se você está construindo um produto com suporte a dark mode ou tematização, Variables são o caminho. Vamos explorar tudo no Módulo 3.

Resumo

  • Color Styles: paletas e gradientes reutilizáveis. Nomear como Brand/Primary, Semantic/Error.
  • Text Styles: escala tipográfica completa. Nomear como Heading/H1, Body/Default.
  • Effect Styles: sombras e blurs padronizados para manter elevação consistente.
  • Layout Grid Styles: grids de mobile, tablet e desktop compartilhados.
  • Use / para criar grupos e subgrupos — o painel Assets organiza automaticamente.
  • Styles são ideais para projetos simples; Variables (Módulo 3) para temas e tokens avançados.
✍️ Exercício

Fundação de Styles de um produto

  1. Crie pelo menos 6 Color Styles organizados em grupos: Brand/Primary, Brand/Secondary, Neutral/50, Neutral/900, Semantic/Success, Semantic/Error.
  2. Crie pelo menos 4 Text Styles: Heading/H1, Heading/H2, Body/Default, Label/Bold.
  3. Crie um Effect Style de sombra: Shadow/md (ex.: 0 4px 12px rgba(0,0,0,0.08)).
  4. Monte um card simples usando apenas esses styles. Depois, mude a cor do Brand/Primary e observe a propagação no card.
Critério de sucesso: ao mudar a cor do Brand/Primary, todos os elementos do card que usam esse style se atualizam automaticamente.
🏆 Desafio

Dark mode manual com dois conjuntos de styles

Crie dois conjuntos de Color Styles: Light/Background, Light/Surface, Light/Text, e Dark/Background, Dark/Surface, Dark/Text. Monte uma tela usando os styles Light. Depois, duplique a tela e manualmente troque todos os Color Styles para os equivalentes Dark. (Nota: esse processo manual é justamente o que Variables automatizam — você vai apreciar ainda mais o Módulo 3 depois disso!)

QuizTeste seu conhecimento

1. Você criou o Color Style "Brand/Primary" com cor roxa e aplicou em 80 botões. O cliente quer mudar para azul. O que você deve fazer?

  • Editar o Color Style "Brand/Primary" uma única vez — todos os 80 botões se atualizam
  • Selecionar os 80 botões e mudar a cor manualmente em cada um
  • Criar um novo style "Brand/Primary Blue" e reaplicar em cada botão
  • Usar Find & Replace para trocar a cor
Esse é o principal benefício dos Styles: editar o style uma única vez propaga a mudança para todos os elementos vinculados. Sem styles, você faria a mudança manualmente nos 80 botões.

2. Qual convenção de nomenclatura é recomendada para organizar styles em grupos no painel?

  • Espaço: "Brand Primary"
  • Sublinhado: "Brand_Primary"
  • Barra: "Brand/Primary"
  • Ponto: "Brand.Primary"
A barra / cria grupos hierárquicos no painel de styles. Brand/Primary e Brand/Secondary aparecem agrupados em "Brand". Espaços, underscores e pontos não criam hierarquia.

3. Qual recurso é necessário para implementar dark mode automático (trocar todo o tema de claro para escuro com um clique)?

  • Styles com grupos Light/ e Dark/
  • Variables com modos Light e Dark
  • Variants com state Light e Dark
  • Effect styles com blur diferente por tema
Variables com modos é o recurso correto para dark mode automático. Um único variable de cor pode ter valores diferentes para o modo Light e Dark — ao trocar o modo do frame, todas as cores mudam de uma vez. Styles não suportam modos nativos.
