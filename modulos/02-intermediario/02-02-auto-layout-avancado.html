Auto Layout — avançado

Você já sabe aplicar Auto Layout. Agora vem a parte que transforma seus designs em sistemas de verdade: controlar como cada elemento reage ao redimensionamento, dobrar linhas como o CSS faz, e posicionar elementos de forma absoluta dentro do container.

⏱️ Leitura: ~22 min 🎯 Nível: Intermediário 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Distinguir e aplicar os três modos de resizing: Hug contents, Fill container e Fixed;
  • Configurar alinhamento e distribuição internos (Packed vs Space between);
  • Criar grades de tags com o modo Wrap;
  • Definir min/max width e height para layouts fluidos;
  • Usar Absolute position para elementos "flutuantes" dentro do Auto Layout;
  • Controlar a ordem de empilhamento (z-index) e o padding individual por lado.

O conceito-chave: Resizing

O Resizing é a pergunta mais importante do Auto Layout: "quando o container mudar de tamanho, o que acontece com este elemento?". O Figma oferece três respostas.

Os três modos de Resizing. O mesmo princípio se aplica tanto à largura (W) quanto à altura (H).

Hug contents — "abraça o conteúdo"

Hug contents faz o container encolher ou crescer para envolver exatamente seu conteúdo. É o comportamento natural de um botão: quando o texto aumenta, o botão cresce junto. No código, equivale a não definir largura explícita — o tamanho é ditado pelo conteúdo.

Use Hug quando o frame deve se adaptar ao que está dentro: botões, chips, tags, badges, tooltips.

Fill container — "preenche o espaço"

Fill container faz o elemento crescer para ocupar todo o espaço disponível dentro do seu Auto Layout pai. Pense em uma coluna de texto em um layout de duas colunas: você quer que ela preencha o restante. No CSS é equivalente a flex: 1.

Use Fill em elementos que devem se expandir para preencher espaço vazio: campo de input, conteúdo principal, barra de progresso, separadores.

Fixed — "tamanho fixo"

Fixed bloqueia a dimensão em um valor específico. O elemento não cresce nem encolhe independentemente do container ou do conteúdo. Use quando um elemento precisa de dimensão exata: uma imagem de thumbnail sempre 80×80, um avatar sempre 40×40, uma sidebar sempre 320 px.

Como alterar o Resizing

Selecione o elemento filho dentro do Auto Layout. No painel direito, você verá dois campos de dimensão (W e H) com um ícone de seta ao lado. Clique nesse ícone para alternar entre Hug, Fill e Fixed. Você também pode clicar com o botão direito no valor de W ou H e escolher o modo.

Spacing Mode: Packed vs Space between

Dentro do painel de Auto Layout, o campo de gap pode operar em dois modos:

  • Packed: os itens ficam agrupados (com o gap que você definiu entre eles) e o alinhamento controla onde o grupo fica dentro do frame. É o comportamento padrão.
  • Space between: o espaço disponível é distribuído entre os itens, empurrando o primeiro para a borda inicial e o último para a borda final. Equivale ao justify-content: space-between do Flexbox.

Alinhamento interno

A grade de 9 botões de alinhamento no painel de Auto Layout controla onde os itens ficam posicionados dentro do container. Em direção horizontal, você controla:

  • Alinhamento vertical dos filhos: topo, centro ou base da linha.
  • Distribuição horizontal: Packed (agrupados) ou Space between.

Em direção vertical, os papéis se invertem. Pense na grade como uma combinação de justify-content + align-items do Flexbox.

Alinhamento baseline

Em direção horizontal, existe ainda o alinhamento baseline: os textos de diferentes tamanhos se alinham pela linha de base tipográfica, como se estivessem na mesma régua invisível. Use em linhas mistas com ícones + texto de tamanhos variados.

Wrap: quebra de linha automática

O modo Wrap (ícone de seta que vira para baixo no seletor de direção) é o equivalente ao flex-wrap: wrap do CSS. Quando os itens não cabem em uma linha, eles "quebram" para a próxima linha automaticamente.

É perfeito para:

  • Grades de tags/chips: tags de categoria que se adaptam ao número de itens.
  • Galerias: miniaturas de fotos que se reorganizam conforme a largura.
  • Listas de botões de filtro: botões que quebram para não passar da largura do container.

Min/Max Width e Height

Para criar layouts verdadeiramente fluidos, você pode definir limites para as dimensões dos elementos. Isso é especialmente poderoso combinado com Fill container:

  • Min Width: o elemento nunca fica mais estreito do que esse valor, mesmo que o container encolha.
  • Max Width: o elemento não ultrapassa esse valor, mesmo que haja mais espaço disponível.
  • Min/Max Height: o mesmo princípio aplicado à altura.

Para definir, selecione o elemento, clique nos campos W ou H e ative os campos Min/Max que aparecem ao expandir a seção.

Caso prático: campo de busca

Um campo de busca em um header geralmente tem Fill container para crescer junto com o header, mas com Min Width: 200px (não encolhe demais em telas menores) e Max Width: 480px (não fica largo demais em monitores grandes). Isso reflete exatamente o flex: 1; min-width: 200px; max-width: 480px do CSS.

Absolute position dentro do Auto Layout

Às vezes você precisa de um elemento que "flutua" sobre o layout sem empurrar os outros — um badge de notificação sobre um ícone, uma sobreposição de texto sobre uma imagem, um botão "fechar" no canto de um modal.

O Figma resolve isso com a opção Absolute position (ou "Absolute" no painel de Constraints quando dentro de um Auto Layout). Para ativar:

  1. Selecione o elemento filho dentro de um frame com Auto Layout.
  2. Ative Absolute position. No painel direito, clique nos três pontos (⋯) da seção Auto Layout, ou procure o botão de posição absoluta ao lado dos campos de alinhamento. Também pode usar Ctrl + Alt + A (Windows) / ⌘ + ⌥ + A (Mac).
  3. Posicione com Constraints. O elemento agora se comporta como se estivesse em um frame normal. Use os campos X/Y ou as Constraints para ancorar à posição desejada (ex.: canto superior direito = Right + Top).
Absolute position não empurra irmãos

Um elemento com Absolute position é ignorado pelo sistema de layout. Ele não ocupa espaço no fluxo, não conta para o gap e não influencia o tamanho do frame se este estiver em modo Hug. É exatamente como position: absolute remove o elemento do fluxo no CSS.

Ordem de empilhamento (z-index no Figma)

Dentro de um Auto Layout, a ordem de empilhamento (quem fica "em cima" de quem) é controlada pela posição na lista de camadas (canvas stacking). Diferente do CSS onde o z-index é um número explícito, no Figma a regra é simples:

  • Camadas mais abaixo na lista do painel de Layers ficam na frente visualmente.
  • Camadas mais acima na lista ficam atrás.

Para reordenar, arraste as camadas na lista ou use Ctrl + [ / ] para mover para baixo/cima na pilha.

Por que essa lógica parece invertida?

O Figma segue a convenção de softwares de design (Illustrator, Sketch): a camada do topo da lista é desenhada por último, mas visualmente aparece "na frente". Quando você usa Absolute position com um badge sobre um ícone, o badge deve estar abaixo do ícone na lista de camadas para aparecer na frente.

Padding individual por lado

Por padrão, o padding pode ser uniforme (um valor para todos os lados) ou vertical/horizontal separados. Mas você pode definir um valor independente para cada lado: topo, base, esquerda e direita.

Para isso, clique no ícone de padding no painel (parece um quadrado com setas) para expandir os quatro campos individualmente. Isso permite, por exemplo, um botão com padding: 12px 20px 12px 16px para acomodar visualmente um ícone à esquerda.

Exemplo de uso real

1. Header com Space between

Um header full-width de aplicativo é o exemplo clássico de Space between. O frame tem largura Fill container (ou Fixed na largura da tela), padding horizontal de 20px, e gap em Space between. Dentro: um grupo com logo + nome (agrupados com gap 8) e um grupo com ícones de ação (agrupados com gap 4). O espaço do meio se distribui automaticamente.

2. Lista de tags com Wrap

Em uma página de produto de e-commerce, as tags de especificação (Bluetooth, NFC, IP68, etc.) ficam em um Auto Layout horizontal com Wrap ativado, gap de 8 e padding de 12. Quando o designer redimensiona o frame ou a equipe de desenvolvimento muda a viewport, as tags quebram para novas linhas automaticamente — sem nenhum ajuste manual.

Resumo

  • Hug contents abraça o conteúdo; Fill container expande para preencher; Fixed bloqueia a dimensão.
  • Space between distribui o espaço entre os itens — fundamental para headers e navbars.
  • Wrap quebra itens para a próxima linha automaticamente — perfeito para grades de tags.
  • Min/Max criam limites para layouts fluidos sem quebrar o design em extremos.
  • Absolute position remove o elemento do fluxo — use para badges, overlays e botões flutuantes.
  • A ordem na lista de camadas define o empilhamento visual (quem fica na frente).
