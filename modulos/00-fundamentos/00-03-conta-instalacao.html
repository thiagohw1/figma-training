Conta, planos e instalação

Em menos de 5 minutos você vai ter o Figma pronto para usar — seja no navegador ou no app desktop. Vamos do zero: criar a conta, entender os planos e configurar o ambiente ideal para estudar.

⏱️ Leitura: ~14 min 🎯 Nível: Fundamentos 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Criar uma conta gratuita no Figma em menos de 5 minutos;
  • Entender as diferenças entre os planos Starter, Professional, Organization e Enterprise;
  • Decidir quando usar o Figma no navegador vs. o app desktop;
  • Instalar o app desktop e o font installer para usar fontes locais;
  • Configurar as preferências iniciais da sua conta.

Criando sua conta gratuita

O plano gratuito do Figma (Starter) é generoso o suficiente para aprender e trabalhar em projetos pessoais. Veja o passo a passo:

  1. Acesse figma.com. Abra o navegador e vá para figma.com. Clique em "Get started for free" ou "Sign up" no canto superior direito.
  2. Escolha o método de cadastro. Você pode se cadastrar com e-mail e senha, com sua conta Google, ou com sua conta SSO corporativa (se aplicável). Para uso pessoal, Google é a opção mais rápida.
  3. Confirme o e-mail (se necessário). Se você usou e-mail e senha, o Figma envia um link de confirmação. Clique nele antes de continuar.
  4. Preencha o onboarding. O Figma vai perguntar sua função (designer, developer, etc.) e o tamanho da sua equipe. Responda honestamente — isso personaliza o painel inicial. Você pode alterar depois.
  5. Você está dentro! O Figma abre a tela inicial com seu espaço de Drafts (rascunhos) e Templates sugeridos. Explore à vontade — nada que você clicar vai custar nada.
Use e-mail profissional se puder

Se você usa um e-mail corporativo (ex.: @empresa.com.br), pode ser elegível para planos de equipe com desconto ou subsídio. Se estiver estudando, e-mails de universidades (.edu) muitas vezes dão acesso a recursos do plano Professional gratuitamente.

O limite de 3 arquivos no Starter

O plano gratuito permite apenas 3 arquivos de Design editáveis em Drafts. Porém, você pode ter arquivos ilimitados em projetos de equipe (Teams) quando você é convidado por alguém com plano pago. Para este curso, 3 arquivos são suficientes — use um por módulo ou arquive os arquivos antigos para liberar espaço.

Figma no navegador vs. app desktop

O Figma funciona perfeitamente no navegador, mas o app desktop oferece algumas vantagens. Entenda quando usar cada um:

Figma no navegador

Funciona em Chrome, Edge, Firefox e Safari modernos. A experiência é praticamente idêntica ao app desktop. Use o navegador quando:

  • Você está em um computador que não é seu (trabalho, escola, biblioteca).
  • Você quer abrir o Figma rapidamente sem instalar nada.
  • Você está acessando apenas para visualizar ou comentar um arquivo.

App desktop (recomendado para uso regular)

Disponível para Windows e Mac. O app oferece:

  • Fontes locais: acesso às fontes instaladas no seu sistema operacional (sem o font installer adicional).
  • Melhor desempenho em arquivos grandes: menos overhead do navegador.
  • Atalhos sem conflito: atalhos de teclado não conflitam com atalhos do navegador (ex.: Ctrl + W fecha uma aba no Chrome, mas funciona normalmente no app).
  • Modo offline: você pode trabalhar sem internet e sincronizar quando reconectar.
  • Notificações do sistema: receba alertas de menções e comentários.
Recomendação deste curso

Para acompanhar as lições, use o app desktop. Isso evita conflitos de atalho e dá acesso às fontes locais que usamos em alguns exercícios.

Instalando o app desktop

  1. Acesse a página de downloads. Vá para figma.com/downloads e escolha a versão para seu sistema operacional: Windows (instalador .exe) ou macOS (arquivo .dmg ou via Mac App Store).
  2. Execute o instalador (Windows). Baixe o arquivo FigmaSetup.exe e execute. O Figma se instala automaticamente na pasta de usuário — não precisa de privilégios de administrador. Após a instalação, o app abre sozinho.
  3. Instale via DMG (Mac). Baixe o Figma.dmg, abra-o e arraste o ícone do Figma para a pasta Applications. Na primeira abertura, confirme que quer abrir um app baixado da internet.
  4. Faça login. O app vai pedir suas credenciais. Use o mesmo e-mail da sua conta. Se você usa Google Login, clique em "Continue with Google".
  5. Instale o Font Installer (Windows). Na página de downloads, há também o Figma Font Installer. Instale-o separadamente se quiser usar fontes locais do Windows. No Mac, as fontes locais já funcionam sem instalação adicional no app desktop.

App Figma para celular

O Figma app para iOS e Android não é um editor — ele serve para visualizar e apresentar protótipos. É perfeito para testar como o design vai ficar no tamanho real da tela do celular, sem precisar exportar nada.

Para usar:

  1. Instale o Figma (iOS: App Store / Android: Google Play).
  2. Faça login com sua conta.
  3. No app desktop ou navegador, com um Frame selecionado, pressione Ctrl/⌘ + Shift + P para abrir o Preview no celular automaticamente.
Por que visualizar no celular importa

Um design que parece ótimo em monitor de 27" pode ter textos minúsculos ou botões difíceis de tocar quando visto no celular. Testar protótipos no dispositivo real é uma prática essencial de design — e o app do Figma torna isso trivial.

Ajustes iniciais da conta

Depois de instalar, configure estas preferências antes de começar:

Tema do app

Vá em Menu principal → Preferences → Themes e escolha entre System default (segue o tema do OS), Light (interface clara) ou Dark (interface escura). Para o canvas, você pode ajustar a cor separadamente via Right-click no canvas → Canvas color.

Preferências gerais

Em Menu principal → Preferences você encontra:

  • Snap to geometry: ativa o encaixe automático nas bordas de outros elementos. Recomendado manter ativo.
  • Nudge amount: define quantos pixels cada pressionamento de seta move um elemento. O valor padrão é 1px (seta) e 10px (Shift + seta). Muitos profissionais mudam o nudge grande para 8px para trabalhar em grid de 8pts.
  • Reduce motion: reduz animações da interface para quem tem sensibilidade a movimento.

Foto de perfil

Vá em figma.com/account para adicionar uma foto. Isso importa porque, em arquivos colaborativos, seu cursor aparece para outros com seu nome e foto.

Resumo

  • Criar uma conta gratuita no Figma leva menos de 5 minutos via figma.com.
  • O plano Starter (gratuito) suporta 3 arquivos editáveis — suficiente para todo este curso.
  • O app desktop oferece fontes locais, melhor performance e atalhos sem conflito com o navegador.
  • O font installer é necessário no Windows para usar fontes locais no navegador; no app desktop e no Mac, as fontes locais já funcionam automaticamente.
  • O app móvel serve para visualizar protótipos no dispositivo real, não para edição.
✍️ Exercício

Configure seu ambiente

  1. Crie sua conta gratuita em figma.com (ou confirme que já tem uma).
  2. Baixe e instale o app desktop para seu sistema operacional.
  3. Abra o app, faça login e explore a tela inicial.
  4. Vá em Preferences e altere o nudge amount (large) para 8.
  5. Se tiver um celular, instale o app Figma (iOS ou Android) e faça login.
Critério de sucesso: o app desktop está instalado, você está logado e o nudge amount foi alterado para 8px.
