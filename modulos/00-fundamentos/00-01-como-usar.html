Como usar este treinamento + roadmap

Bem-vindo(a)! Antes de abrir o Figma pela primeira vez, vamos garantir que você aproveite cada lição ao máximo — porque a forma como você estuda importa tanto quanto o que você estuda.

⏱️ Leitura: ~12 min 🎯 Nível: Fundamentos 🛠️ Pratique junto no Figma

Ao final desta lição você será capaz de

  • Entender como o curso está organizado em módulos e níveis;
  • Navegar pelo site com eficiência usando atalhos de teclado e a barra lateral;

  • Saber exatamente quais são os pré-requisitos e quanto tempo investir.

Navegando pelo site

O site foi projetado para que você consiga estudar sem tirar as mãos do teclado. Veja os recursos disponíveis:

Barra lateral (sidebar)

A sidebar fica à esquerda e mostra todos os módulos com suas lições. Cada lição exibe um indicador de conclusão: um círculo vazio significa "não concluída", e um círculo verde com ✓ significa "concluída". Clique no título de um módulo para expandir ou recolher suas lições.

Busca rápida

Pressione / em qualquer página para abrir a busca. Comece a digitar e os resultados aparecem em tempo real. Pressione Enter para ir à primeira sugestão ou use as setas do teclado para navegar.

Navegação entre lições

No final de cada lição há botões Anterior e Próximo. Você também pode usar os atalhos Alt + ← (voltar) e Alt + → (avançar) em qualquer momento — sem precisar rolar até o fim da página.

Tema claro / escuro

O botão de sol/lua no canto superior direito alterna entre tema claro e escuro. Sua preferência é salva automaticamente no navegador e persiste entre sessões.

Marcar lição como concluída

Ao terminar uma lição, clique no botão "Marcar como concluída" no rodapé. A barra de progresso no topo do site se atualiza e o ícone na sidebar muda para verde. Isso ajuda você a saber exatamente de onde retomar os estudos.

Barra de progresso

A barra colorida no topo mostra sua porcentagem geral de conclusão do curso. Ela é calculada a partir das lições que você marcou como concluídas — uma motivação visual para continuar!

Como estudar de verdade

Existe uma grande diferença entre ler sobre o Figma e saber usar o Figma. Para que o conhecimento de fato se consolide, siga estas práticas:

  1. Abra o Figma ao lado. Coloque o browser com o curso em uma metade da tela e o Figma na outra. No Windows use Win + ←/→ para encaixar janelas; no Mac use Mission Control ou Stage Manager.
  2. Refaça cada passo enquanto lê. Não leia uma seção inteira para só então executar. Leia um passo, execute no Figma, volte, leia o próximo. Aprender design é como aprender a tocar um instrumento: é a prática repetida que forma o músculo.
  3. Faça o exercício obrigatório. Cada lição tem um bloco Exercício com critério de sucesso claro. Não pule — é aqui que o aprendizado se solidifica.
  4. Tente o desafio. O bloco Desafio é opcional, mas vai além do exercício. É onde você desenvolve autonomia e criatividade. Se travar, volte à lição e releia com atenção.
  5. Responda o quiz. Cada lição termina com 3 perguntas. Se errar, a explicação aparece automaticamente. É normal errar — o objetivo é identificar lacunas, não punir.
  6. Marque como concluída e siga em frente. Perfeccionismo é inimigo do progresso. Avance mesmo que não tenha dominado tudo — você vai revisitar conceitos à medida que o curso avança.
Evite o modo "maratona passiva"

Fazer várias lições seguidas só lendo, sem praticar, cria a ilusão de aprendizado. Seu cérebro reconhece o conteúdo quando você lê, mas não consegue reproduzir quando você está sozinho no Figma. Praticar é insubstituível.

O que você vai construir

Teoria sem projeto é conhecimento solto. Por isso, ao longo do curso você vai construir dois produtos reais do zero:

App mobile "FinView" (Módulo 4)

Um aplicativo de finanças pessoais para iOS e Android. Você vai criar o fluxo completo: onboarding, dashboard de gastos, tela de transações, perfil e configurações. O projeto usa Auto Layout, Variants, Variables de cor e prototipagem animada.

Dashboard web "TaskFlow" (Módulo 4)

Um dashboard de gestão de tarefas para desktop e tablet. Você vai projetar sidebar de navegação, cards de métricas, tabela de dados, modal de criação e modo escuro usando Variables. O handoff para dev será feito via Dev Mode.

Por que dois projetos?

Mobile e web têm lógicas diferentes: tamanho de toque vs. clique, densidade de informação, orientação da tela, adaptação de componentes. Projetar os dois vai te preparar para a maioria dos cenários reais do mercado.

Pré-requisitos

Este treinamento foi feito para ser acessível a qualquer pessoa que queira aprender design de interfaces. O único pré-requisito é:

  • Uma conta Figma gratuita — o plano Starter é suficiente para todas as lições. Veja como criar na próxima lição.
  • Inglês básico para leitura da interface — os menus do Figma estão em inglês, mas todas as explicações deste curso são em português.

Não é necessário saber programar, ter experiência em design gráfico ou ter usado qualquer outra ferramenta de design antes. Se você já usou Photoshop, Illustrator ou PowerPoint, vai se sentir ainda mais à vontade — mas não é obrigatório.

Tempo estimado

Cada lição tem em média 15–20 minutos de leitura + prática. Considerando exercícios e desafios, planeje cerca de 25–35 minutos por lição. Com dedicação de 1 hora por dia, você conclui o curso em aproximadamente 6 semanas.

Dica de ritmo

Estudar 3–4 lições por semana, com prática diária no Figma, é mais eficaz do que fazer 10 lições em um fim de semana. O espaçamento temporal consolida a memória de forma muito mais duradoura.

Exemplo de uso real

Imagine que você é um(a) designer júnior começando seu primeiro projeto profissional. O roadmap deste curso reflete exatamente o que você vai precisar:

  • No primeiro dia você vai precisar criar o arquivo e as páginas (Módulo 0).
  • Na primeira semana você vai precisar criar shapes, textos e um componente básico (Módulo 1).
  • Após o primeiro mês você vai precisar montar o design system da empresa com Auto Layout e Components (Módulo 2).
  • Após três meses você vai precisar usar Variables para o modo escuro e entregar via Dev Mode (Módulo 3).
